# 연습 폴더를 만들고 첫 요청을 보내요

## 이 장을 마치면

내 컴퓨터에 가짜 파일 20개가 든 연습 폴더가 생겨요. 클로드 코드가 그 폴더 안의 파일을 읽고 정리한 파일 목록 표도 대화창에 남아요.

## 먼저 알아둘 것

클로드 코드가 볼 수 있는 곳은 세션을 시작할 때 고른 폴더 하나예요. 이 폴더를 작업 폴더라고 불러요. 작업 폴더 밖의 파일은 따로 허락하지 않는 한 건드리지 않아요.

그래서 첫 연습은 빈 폴더에서 시작해요. 진짜 업무 파일이 든 폴더를 고르면, 요청을 조금만 잘못 써도 중요한 파일 이름이 바뀔 수 있어요. 연습 폴더에는 일부러 만든 가짜 파일만 있으니 무엇이 바뀌어도 잃는 것이 없어요.

가짜 파일은 클로드 코드에게 만들어 달라고 해요. 메모는 `.txt`, 표는 `.csv`, 그림은 `.svg` 파일로 만들어요. 세 가지 모두 메모장으로도 열리는 가벼운 파일이라, 만든 뒤에 내용을 바로 확인할 수 있어요.

파일 이름은 일부러 어지럽게 만들어요. "최종", "수정", "(2)"가 섞이고 날짜 모양도 제각각인 이름들이에요. 이런 이름을 하나의 규칙으로 바꾸는 것이 4장과 5장에서 할 일이에요.

입력 상자 아래 줄의 칸은 세 개만 기억하면 돼요. 첫 칸은 어디서 일할지(환경), 둘째 칸은 어느 폴더에서 일할지(작업 폴더), 오른쪽 끝 칸은 얼마나 묻고 일할지(권한 모드)예요.

환경은 "이 컴퓨터"를 써요. 가운데 카드에 구름 모양 아이콘이 붙은 항목은 클라우드에서 도는 환경이에요. 이 책은 내 컴퓨터의 폴더를 다루기 때문에 쓰지 않아요.

권한 모드는 3장에서 자세히 다뤄요. 이 장에서는 파일 만들기를 매번 묻지 않도록 "편집 자동 수락"으로 바꿔요. 이 모드는 작업 폴더 안에서 파일을 만들고 고치는 일을 묻지 않고 해요. 그래서 반드시 연습 폴더에서만 써요.

## 따라 하기

### 1. 빈 연습 폴더를 만들어요

파일 탐색기(맥은 Finder)에서 "문서" 폴더를 열고, 띄어쓰기 없이 `클로드연습`이라는 새 폴더를 만들어요.

성공: "문서" 폴더 안에 빈 `클로드연습` 폴더가 생겨요.

안 되면: 같은 이름의 폴더가 이미 있고 안에 다른 파일이 들어 있으면, 새 이름으로 폴더를 하나 더 만들어요.

폴더 안은 비워 둬요. 파일은 4단계에서 클로드 코드가 만들어요. 빈 폴더에서 시작해야 나중에 세는 파일 수가 정확히 20개가 돼요.

### 2. 새 세션을 열고 연습 폴더를 골라요

사이드바의 **새로 만들기**를 누르고, 입력 상자 밑의 폴더 칸에서 **폴더 열기…**로 `클로드연습`을 골라요.

![입력 상자 아래 폴더 칸을 누르면 열리는 목록과 맨 아래의 폴더 열기](/books/claude-code-start/ch2-folder-menu.svg)

성공: 폴더 칸에 `클로드연습`이 보여요.

안 되면: 폴더 칸에 "폴더 없음"이 보이면 아직 작업 폴더를 고르지 않은 거예요. 폴더 칸을 눌러 다시 골라요.

한 번 연 폴더는 다음부터 목록의 "최근"에 나와요. 2장 이후로는 거기서 바로 고르면 돼요.

### 3. 환경과 권한 모드를 확인해요

입력 상자 아래 줄의 첫 칸이 "이 컴퓨터"인지 보고, 오른쪽 끝의 권한 모드 칸에서 **편집 자동 수락**을 골라요.

![권한 모드 목록에서 편집 자동 수락을 고르는 모습](/books/claude-code-start/ch2-mode-menu.svg)

성공: 첫 칸에 "이 컴퓨터", 권한 모드 칸에 "편집 자동 수락"이 보여요.

안 되면: 첫 칸에 다른 이름이 보이면 눌러서 "이 컴퓨터"를 골라요. 구름 모양 아이콘이 붙은 항목은 클라우드에서 도는 환경이라 내 컴퓨터의 폴더를 쓰지 않아요.

편집 자동 수락은 설명에 "모든 파일 편집을 자동으로 수락"이라고 적힌 항목이에요. 권한 모드는 3장에서 자세히 다뤄요.

공식 안내에 따르면 데스크톱 앱은 고른 권한 모드를 폴더마다 기억해요. 연습 폴더에서 고른 모드가 다른 폴더로 따라가지 않으니 안심해도 돼요. 그래도 새 세션을 열 때마다 이 칸을 한 번씩 보는 습관을 들여요.

### 4. 가짜 파일 20개를 만들어 달라고 해요

입력 상자에 아래 입력값을 붙여넣고 Enter를 눌러요.

```입력값 1
이 폴더는 정리 연습용이야. 여기에 가짜 파일 20개를 만들어줘.
- 종류: 메모(.txt) 8개, 표(.csv) 6개, 그림(.svg) 6개
- 이름은 일부러 어지럽게: 날짜가 있거나 없고, "최종", "수정", "(2)" 같은 말이 섞이게
- 내용은 몇 줄만 짧게. 실제 사람 이름이나 연락처는 넣지 마
- 하위 폴더는 만들지 말고 이 폴더에 바로 만들어
다 만들면 만든 파일 이름을 목록으로 보여줘.
```

성공: 클로드 코드가 파일을 하나씩 만든 뒤 이름 목록을 보여주고, 그 수가 20개예요.

안 되면: 파일이 모자라면 "모자란 파일을 마저 만들어줘"라고 보내요.

클로드 코드가 일하는 동안 대화창에 파일을 만드는 과정이 차례로 보여요. 중간에 멈추고 싶으면 중지 버튼을 누르면 돼요.

멈추지 않고 방향만 바꾸고 싶으면, 입력 상자에 고칠 점을 적어 Enter를 눌러도 돼요. 공식 안내에 따르면 하던 일을 끝까지 기다리지 않아도 고친 요청이 전달돼요.

### 5. 파일 탐색기에서 직접 확인해요

파일 탐색기(맥은 Finder)에서 `클로드연습` 폴더를 다시 열고, `.txt` 파일 하나를 메모장으로 열어 봐요.

성공: 대화창에 나온 이름과 같은 파일들이 보이고, 메모에는 짧은 글이 들어 있어요.

대화창의 결과와 내 컴퓨터의 파일이 같다는 것을 눈으로 확인하는 단계예요. 클로드 코드는 화면 속이 아니라 내 컴퓨터의 진짜 폴더에서 일해요.

### 6. 파일 목록 표를 받아요

같은 대화에 아래 입력값을 보내요.

```입력값 2
이 폴더에 있는 파일을 모두 표로 정리해줘.
열은 파일 이름 / 종류 / 내용 한 줄 요약으로 하고, 종류별로 묶어서 보여줘.
아직 아무 파일도 옮기거나 이름을 바꾸지 마.
```

성공: 종류별로 묶인 표가 나오고, 메모 8개, 표 6개, 그림 6개예요.

안 되면: 개수가 다르면 지금 고쳐 두는 편이 좋아요. 4장부터는 이 20개를 기준으로 계획을 세우기 때문이에요.

이 표는 4장에서 정리 계획을 세울 때 다시 써요. 요약 칸도 훑어봐요. 내용이 비슷한 파일이 둘 이상 보이면 표시해 둬요. 같은 내용인데 이름만 다른 파일을 어떻게 할지는 4장에서 정해요.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 폴더 칸에 "폴더 없음"이 보여요 | 아직 작업 폴더를 고르지 않았어요 | 폴더 칸을 눌러 **폴더 열기…**로 연습 폴더를 골라요 |
| 파일을 만들 때마다 허락을 물어요 | 권한 모드가 "수동"이에요 | 권한 모드 칸에서 **편집 자동 수락**을 골라요. 이미 물어본 것은 허락해도 돼요 |
| 파일이 다른 곳에 생겼어요 | 다른 폴더를 작업 폴더로 골랐어요 | 폴더 칸의 이름을 확인하고, 새 세션에서 연습 폴더를 다시 골라요 |
| 표가 아니라 긴 글로 나와요 | 요청에 표 형식이 빠졌어요 | "표로 다시 보여줘"라고 한 번 더 보내요 |

결과가 이상하면 같은 대화에서 계속 고치지 말고 새 세션을 열어요. 사이드바의 **새로 만들기**를 누르고 폴더를 다시 고른 뒤, 입력값 1부터 다시 보내면 돼요.

만든 파일이 마음에 들지 않으면 연습 폴더를 통째로 지우고 1단계부터 다시 해도 돼요. 연습 폴더를 따로 만든 이유가 바로 이거예요.

## 나쁜 예와 좋은 예

| 구분 | 요청 | 결과 |
|---|---|---|
| 나쁜 예 | "문서" 폴더 전체를 작업 폴더로 고르고 "정리해줘"라고 보내요 | 무엇을 기준으로 정리할지 몰라서, 내가 원하지 않는 파일까지 바뀔 수 있어요 |
| 좋은 예 | 빈 연습 폴더를 고르고 입력값 1로 만들 파일을 정해서 보내요 | 개수, 종류, 이름 규칙이 정해져 있어서 결과를 바로 확인할 수 있어요 |
| 나쁜 예 | "파일 목록 보여줘" | 이름만 줄줄이 나와서 다음 단계에 쓰기 어려워요 |
| 좋은 예 | 입력값 2처럼 열 이름과 묶는 기준을 정하고 "아직 바꾸지 마"를 붙여요 | 4장에서 바로 쓸 수 있는 표가 나오고, 파일은 그대로 남아요 |

두 쌍 모두 달라진 것은 요청에 담은 조건이에요. 클로드 코드는 내 폴더를 직접 다루기 때문에, 무엇을 하고 무엇을 하지 말지 먼저 정해 주는 것이 안전해요.

특히 "아직 바꾸지 마"는 이 책 내내 쓰는 한 줄이에요. 확인만 하고 싶을 때 이 한 줄을 붙이면 파일은 건드리지 않고 결과만 받아요.

## 점검표

- [ ] 문서 폴더 안에 빈 `클로드연습` 폴더를 만들었어요
- [ ] 폴더 칸에 `클로드연습`, 첫 칸에 "이 컴퓨터"가 보여요
- [ ] 권한 모드를 "편집 자동 수락"으로 바꿨어요
- [ ] 가짜 파일 20개가 파일 탐색기에서도 보여요
- [ ] 종류별로 묶인 파일 목록 표를 받았어요
