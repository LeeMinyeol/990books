## 2. 본문 통독
독자처럼 첫 장부터 끝까지 읽고, 항목마다 **맞음 / 어긋남** 중 하나와 근거가 되는 장 번호를 적는다. 앞에서 불합격이 정해졌어도 끝까지 한다.

| 볼 것 | 맞음 / 어긋남 | 근거 (장 번호, 문장) |
|---|---|---|
| 제목·부제·칩이 약속한 것(결과물, 시간, "한 번에" 같은 말)이 본문에서 실제로 이뤄지는가 | 맞음 | 부제 "연습 폴더를 정리하고 규칙을 문서로 남겨 정리해줘 한마디로 다시 돌린다"는 4·5장(정리), 6장(CLAUDE.md와 "정리해줘"), 7장(진짜 폴더) 순서로 이뤄진다. 칩 "120분"은 주제 카드의 어림값이고 실제로 재지 않았다(6번에 적음) |
| 숫자가 서로 같은가 (장 수, 입력값 수, 걸리는 시간, 개수) | 맞음 | 챕터 7개, 입력값 12개(검사기). 2장 메모 8+표 6+그림 6=20, 6장 2+2+1=5, 6장 "20줄 아래 새 줄 5개". 걸리는 시간 120분은 칩·준비물·상세페이지가 같다 |
