# 990books 와이어프레임 (저충실도 + 주석)

규칙: 회색·검정만 사용, `[ ]`는 버튼, `▒▒▒`는 이미지, `~~~`는 글. 번호 ①②는 콘텐츠 우선순위예요.
충실도 단계: 지금은 **Low-fi → 뷰어는 이미 Mid-fi 구현됨**. 나머지 화면은 아래 Low-fi가 기준이에요.

## 1. 사이트맵

```
홈 /                                     책 목록
├─ 책 상세 /books/<slug>                 블록을 조합한 판매 페이지
│   └─ 뷰어 /books/<slug>/read           결제 전에는 앞 3장만, 결제 후 전체
├─ 오늘의 칼럼 /columns                  무료 글 목록
│   └─ 글 /columns/<slug>
├─ 로그인 (구글·카카오·이메일)          ← 미구현
├─ 내 서재 / 나의 기록                  ← 미구현
└─ 후기 관리(관리자)                    ← 미구현
뷰어 장 순서
- 슬라이드형(미니북·실전 키트): 표지 → 준비물 → 따라 하기 → 요약 → 다음편
- 긴 글형(심화 가이드): 표지 → 준비물 → 챕터 5~7개 → 핵심 단계 → 요약 → 다음편
```

## 2. 사용자 흐름

```
[홈에서 책 카드 선택] → [책 상세: 미리보기·난이도·후기]
      → <로그인했나요?> ─아니오→ [로그인] ┐
                         └예───────────────┤
      → [결제 화면: 환불 규정 고지(열람 전만 환불)] → [결제]
      → [뷰어: 표지 → ... → 마지막 장] → 완독 스탬프
      → <다음편 구매?> ─예→ [다음편 결제]   └아니오→ [내 서재]
재방문: [내 서재] → [이어보기] → 마지막 본 장에서 시작
```

주석
- 헤더: 로고 클릭 = 홈. 로그인 버튼은 자리만 두고, 누르면 "로그인은 준비 중이에요" 안내. 검색은 책이 늘어날 때까지 숨김.
- 캐러셀: 자동 넘김 없음. 화살표 / 스와이프 / 키보드 ← →. "1 / 3" 표시. 준비 중인 책은 버튼 대신 "준비 중이에요" 표시.
- 카드 정보 순서 고정: 필요 도구·추가 비용 → 소요시간·슬라이드 수 → 완독자 후기 평점(후기 3개 이상부터 표시).
- 난이도는 카드에 넣지 않고 상세에 표시. 카드 전체가 하나의 링크(터치 영역 전체).
- 카드 클릭: 공개된 책은 뷰어로 임시 연결(책 상세 페이지는 결제 단계에서 추가). 준비 중 카드는 열리지 않음.
- 가격: 카드마다 반복하지 않고 히어로의 "990원" 도장과 푸터 한 줄로만 표시.

상태
| 상태 | 화면 동작 |
|---|---|
| 책 1권 + 준비 중 2권(현재) | 캐러셀 1/3, 그리드 3칸 |
| 선택한 분야에 책 없음 | "이 분야의 책을 준비하고 있어요" 안내 |
| 표지 이미지 없음 | 포인트컬러 바탕에 제목만 표시 |
| 후기 3개 미만 | 평점 줄을 그리지 않음 |

### 3-2. 책 상세 `/books/<slug>` (2026-11-13 개정)
페이지를 책마다 새로 그리지 않는다. `book.json`의 `detail.blocks`에 적힌 블록을 위에서부터 차례로 그린다. 블록 14종과 순서 규칙은 `detail-page` 스킬에 있다.

┌──────────────────────────────────────────────────────────┐

│ [미니북] AI, 인스타그램            ┌──────────────────┐  │ ① hero

```

주석
- 포인트컬러를 쓰는 곳: hero(band 바탕), 버튼, 체크 표시, 소제목 옆 막대. 본문 글자색으로 쓰지 않는다.
- 버튼 문구는 고정이다: "앞 3장 무료로 보기"(뷰어로 이동), "전체 보기 + 가격"(결제 전에는 "결제는 준비 중이에요" 안내).
- 환불 한 줄은 버튼 바로 아래에 항상 보인다. 문구는 화면에 고정돼 있다.
- `toc`, `preview`, `facts`, `refund`는 책 데이터에서 내용을 만든다. 책마다 쓰는 것은 제목뿐이다.
- `reviews`는 승인된 후기가 3개 이상일 때만, `next`는 이어지는 책이 공개돼 있을 때만 그린다. 조건이 안 맞으면 블록이 있어도 그리지 않는다.
- `detail`이 없는 책은 기본 구성(hero split → includes → preview → toc → facts → refund)으로 그린다.
- 홈의 책 카드는 상세로, 홈 히어로의 "앞 3장 무료로 보기"는 뷰어로 바로 간다.

상태
| 상태 | 화면 동작 |
|---|---|
| 표지 이미지 없음 | hero가 `band`로 바뀐다 |
| 후기 3개 미만 | reviews 블록을 그리지 않는다 |
| 다음 책 미공개 | next 블록을 그리지 않는다 |
| 공개 전 책(`draft`) | 개발 화면에서만 열리고 "공개 전" 띠를 보여준다 |

주석(인터랙션):
- 넘기기: 버튼 / 키보드 ← → / 모바일 좌우 스와이프. 오른쪽·왼쪽 = 다음·이전으로 고정.

### 3-5. 뷰어 긴 글형 장 (심화 가이드 챕터)
슬라이드형과 같은 뷰어, 같은 넘김 버튼을 쓴다. 장이 챕터일 때만 틀이 세로로 길어지고 안에서 스크롤한다.

```
PC (틀 높이 = 화면 높이)                     모바일 세로 전체
┌────────────────────────────────────┐     ┌────────────────┐
│ 책 제목                 4/11 · 36% │ ①   │ 제목   4/11·36%│
│ ▓▓▓▓▓▓░░░░░░░░░░░ 진행 막대        │     │ ▓▓▓░░░░░       │
├──────────┬─────────────────────────┤     │ CHAPTER 2      │
│ 이 장에서│ CHAPTER 2               │ ②   │ 챕터 제목      │
│ ·마치면  │ 챕터 제목(크게)         │     │ [이 장에서 ▾]  │ 접힌 목차
│ ·알아둘것│                         │     │                │
│ ▸따라하기│ ## 이 장을 마치면       │ ③   │ ## 소제목      │
│ ·막히는곳│ ~~~ 본문 (폭 680px) ~~~ │     │ ~~~ 본문 ~~~   │
│ ·나쁜/좋은│ ### 1. 동작            │     │ ### 1. 동작    │
│ ·점검표  │ ┌ 입력값 1     [복사] ┐ │ ④   │ ┌입력값 [복사]┐│
│ (따라옴) │ └ ~~~             ~~~ ┘ │     │ └ ~~~         ┘│
│          │ | 증상 | 원인 | 해결 |  │ ⑤   │ (표는 가로 스크롤)│
│          │ ☐ 점검표 항목           │     │ ☐ 점검표       │
├──────────┴─────────────────────────┤     ├────────────────┤
│ [← 이전]              [다음 →]     │ ⑥   │ [←이전] [다음→]│
└────────────────────────────────────┘     └────────────────┘
```
주석
- 챕터 글은 `src/books/<slug>/chapters/NN-이름.md`다. 서버가 읽어 블록으로 바꿔 보낸다.
- 지원하는 글 요소: 소제목(`##`, `###`), 문단, 굵게, 목록, 표, 이미지, 점검표(`- [ ]`), 입력값 박스.
- 입력값 박스는 코드 울타리 첫 줄에 이름을 적는다: ` ```입력값 1 `. 슬라이드형과 같은 복사 버튼이 붙는다.
- 왼쪽 목차(PC)는 `##` 소제목 목록이다. 누르면 그 자리로 간다. 지금 읽는 소제목을 표시한다.
- 넘기기는 버튼과 키보드 ← →. 긴 글 장에서는 좌우 스와이프로 넘기지 않는다(표를 옆으로 미는 동작과 겹친다).
- 장을 넘기면 맨 위에서 시작한다. 이어보기는 장 단위로 기억한다.

### 3-6. 오늘의 칼럼 목록 `/columns`
```
PC                                              모바일
┌───────────────────────────────────────────┐  ┌────────────────┐
│ 사이트 헤더 (오늘의 칼럼 = 현재 위치)     │  │ 헤더           │
├───────────────────────────────────────────┤  ├────────────────┤
│ 오늘의 칼럼                               │  │ 오늘의 칼럼    │
│ ~~~ 한 줄 설명 ~~~                        │  │ ~~~ 설명 ~~~   │
├───────────────────────────────────────────┤  ├────────────────┤
│ 2026년 11월 12일 · 읽는 데 약 4분         │  │ 날짜 · 약 4분  │
│ 글 제목(크게)                             │  │ 글 제목        │
│ ~~~ 요약 두 줄 ~~~                        │  │ ~~~ 요약 ~~~   │
│ ───────────────────────────────────────── │  │ ────────────── │
│ 날짜 · 읽는 시간                          │  │ ...            │
│ 글 제목                                   │  │                │
└───────────────────────────────────────────┘  └────────────────┘
```
주석: 최신 글이 위. 이미지 없이 제목과 요약만 둔다(글이 주인공). 글이 없으면 "첫 글을 준비하고 있어요".

### 3-7. 오늘의 칼럼 글 `/columns/<slug>`
```
┌───────────────────────────────────────────┐
│ 사이트 헤더                               │
├───────────────────────────────────────────┤
│        오늘의 칼럼 (목록으로)             │ ①
│        글 제목(크게)                      │ ②
│        2026년 11월 12일 · 읽는 데 약 4분  │
│        ─────────────────                  │
│        ~~~ 본문 (폭 680px) ~~~            │ ③ 소제목, 문단, 목록, 표
│        ## 소제목                          │
│        ~~~ ~~~                            │
│        ─────────────────                  │
│        ┌ 이어지는 책 ────────────────┐    │ ④ 내용이 이어지는 책이
│        │ [미니북] 책 제목   990원 →  │    │   있을 때만 1권
│        └─────────────────────────────┘    │
│        [← 목록으로]                       │
└───────────────────────────────────────────┘
```
주석
- 글은 `src/columns/<slug>.md`다. 맨 위에 제목, 날짜, 요약, 이어지는 책(선택)을 적는다.
- 칼럼은 무료 글이라 복사·우클릭을 막지 않는다. 공유되는 것이 목적이다.
- 검수 전인 글(`draft`)은 개발 화면에서만 보이고 "검수 전" 표시가 붙는다.

### 3-8. 무단 배포 방지 (뷰어에만 적용)
```
┌────────────────────────────────────┐
│ 책 제목                 5/12 · 42% │
│      b u y e r @ m a i l . c o m   │ ① 워터마크: 구매자 이메일을
│  STEP 3            b u y e r @ ... │    옅게(불투명도 6%쯤) 비스듬히 반복
│  제목                              │    읽기를 가리지 않는다
│  ~~~ 본문 ~~~   b u y e r @ ...    │    무료 3장에는 넣지 않는다
│ [← 이전]              [다음 →]     │
└────────────────────────────────────┘
개발자도구가 열린 것 같을 때
┌────────────────────────────────────┐
│  이 책은 구매한 분만 볼 수 있어요  │ ② 안내 한 번. 가리고 끝내지 않는다
│  장마다 구매자 이메일이 표시돼요   │
│            [계속 보기]             │
└────────────────────────────────────┘
```
| 막는 것 | 방법 |
|---|---|
| 우클릭 | 뷰어 안에서 메뉴가 뜨지 않는다 |
| 드래그·글자 선택 | 뷰어 본문은 선택되지 않는다. 입력값은 복사 버튼으로만 복사한다 |
| 인쇄 | 인쇄 화면에 내용 대신 "화면에서만 볼 수 있어요" 한 줄 |
| 단축키 | F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S, Ctrl+P (맥은 Cmd+Option) |
| 개발자도구 | 창 크기 비율로 가볍게 감지 → 안내 한 번 |
| 내용 전송 | 결제 전에는 서버가 앞 3장만 보낸다 |

주석
- 감지는 틀릴 수 있다(브라우저 옆 패널, 확대). 그래서 내용을 잠그지 않고 안내만 한다.
- 화면 캡처와 개발자도구는 완전히 막을 수 없다. 속도를 떨어뜨리는 기법(무한 디버거 등)은 쓰지 않는다.
- 터치 기기에서는 감지를 하지 않는다.

## 5. 반응형 규칙
- 1024px 이상: 16:9 프레임(최대 1100px), 이미지와 글을 좌우 2열.
- 1024px 미만: 화면 전체 세로. 이미지가 위, 글이 아래.
- 이미지 비율은 16:10 고정, 슬라이드당 200KB 이하.
