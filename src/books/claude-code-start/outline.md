# 뼈대: claude-code-start

결과물에서 거꾸로 짰다. 결과물은 "정리해줘" 한마디로 다시 돌릴 수 있는 폴더 정리다.
그러려면 규칙이 문서에 있어야 하고(6장), 그 전에 한 번 손으로 정리해 봐야 하고(5장), 그 전에 계획을 받아야 하고(4장), 그 전에 승인하는 법을 알아야 하고(3장), 그 전에 연습 폴더가 있어야 하고(2장), 그 전에 앱이 열려 있어야 한다(1장).

## 뷰어에서 보이는 순서
표지 → 준비물 → 챕터 1~7 → 핵심 단계 4장 → 요약 → 다음편

- 챕터마다 고정 소제목 여섯 개를 쓴다. 분량은 챕터당 공백 제외 2,400~3,200자, 합계 17,000~22,000자를 목표로 한다.
- 입력값 번호는 책 전체에서 1부터 잇는다.

## 핵심 단계(슬라이드)
1. 연습 폴더에서 시작해요
2. 계획을 먼저 받아요
3. 실행할 때 기록을 남겨요
4. 규칙을 안내 문서에 적어요

## 이 책에서 다루지 않는 것
- 터미널 설치, 깃, 플러그인, 예약 작업, 클라우드 세션
- 웹 서비스나 앱 만들기
- 되감기(/rewind): 데스크톱 앱에서 되는지 확인하지 못했다

## 실제 화면에서 확인한 글자 (2026-11-14, 윈도우 한국어 화면, 사용자 캡처)
- Code 탭: 사이드바 맨 위 아이콘 두 개 중 오른쪽 `</>` 아이콘(왼쪽 말풍선은 채팅). "Code" 글자는 보이지 않는다
- 사이드바 메뉴: 새로 만들기, 검색, 아티팩트, 예약됨, 사용자 지정, 그 아래 지난 대화 목록
- 새 세션 화면: 제목 "새 세션", 가운데 환경 카드("환경 선택"), 입력 상자 안내문 "작업을 설명하거나 질문하세요"
- 입력 상자 아래 줄: 왼쪽부터 "이 컴퓨터 ⌄"(환경), 폴더 이름 ⌄, 오른쪽에 모델 이름과 노력 수준(예: Opus 5.5 중간), 권한 모드("자동")
- 폴더 버튼 목록: 폴더 없음 / 최근(폴더 이름들) / 폴더 열기…
- 권한 모드 목록(머리글 "권한 · 이 세션"): 자동(Claude가 권한 결정을 처리합니다), 수동(변경하기 전에 항상 확인), 편집 자동 수락(모든 파일 편집을 자동으로 수락), 계획(변경하기 전에 계획 세우기), 권한 무시(Claude Code 설정에서 활성화, 기본은 꺼져 있음)
- 메뉴: 왼쪽 위 ≡ → 파일, 편집, 보기, 이동, 도움말. 도움말 안에 업데이트 확인…, Claude 정보
- 아직 못 본 것: 권한을 묻는 창의 버튼 글자(3장), 사용량 링을 눌렀을 때 화면(7장). 3장과 7장을 쓰기 전에 캡처를 요청한다

## 캡처 원본
- `.research/claude-code-start/captures/` (저장소에 올라가지 않는다). 10 첫 화면, 11·12 폴더 목록, 13 권한 모드 목록, 14 도움말 메뉴
- 책에 넣을 때는 사이드바 대화 목록, 계정 이름·요금제 표시, 폴더 이름을 가린다

## 3장에 넣을 것 (2장을 쓰며 확인한 사실)
- 2장에서 연습 폴더에 "편집 자동 수락"을 썼다. 공식 문서상 이 모드는 작업 폴더 안의 파일 만들기·고치기와 함께 mkdir, touch, rm, rmdir, mv, cp 같은 명령도 묻지 않고 승인한다. **지우기(rm)도 포함**된다는 점을 3장에서 분명히 쓰고, 진짜 폴더에서는 "수동"이나 "계획"으로 시작하게 한다.
- "수동" 모드에서도 작업 폴더 안의 파일 읽기와 읽기 전용 명령은 묻지 않는다(공식 문서 permission-modes).
- 권한 모드는 폴더마다 기억된다(공식 문서 desktop).
