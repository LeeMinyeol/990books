# 주제 카드: claude-code-start

조사 시트 A-03에서 출발했다(2026-11-14 선정). 시트의 가안과 달라진 점은 맨 아래에 적었다.

- 종류: deep
- 분야와 세부 주제: AI, 파일 정리
- 독자의 상황: 클로드 코드 영상을 여러 편 봤지만 내 컴퓨터에서는 아직 한 번도 켜 보지 못했다면
- 독자가 지금 막힌 곳: 설치 영상을 따라 검은 화면(터미널)에 명령어를 붙여넣다가 오류가 나서 멈췄다
- 그 도구를 처음 쓰는 독자인가: 예
- 결과물 하나: "정리해줘" 한마디로 다시 돌릴 수 있는 폴더 정리. 종류별 폴더로 나뉘고 이름이 규칙대로 바뀐 연습 폴더, 정리 규칙이 적힌 안내 문서(CLAUDE.md), 바꾼 내용을 적은 변경 기록표가 남는다
- 걸리는 시간: 120분 (챕터 7개를 15~20분씩으로 어림한 값. 원고를 다 쓴 뒤 다시 본다)
- 필요한 도구와 버전·요금제:
  - Claude 데스크톱 앱의 Code 탭. macOS 13 이상 또는 Windows 10 이상. 2026년 11월 화면 기준
  - Claude 유료 요금제. Pro 이상이면 Code 탭을 쓸 수 있다(무료 요금제는 안 된다)
- 추가 비용: Pro 요금제 월 20달러(연 결제는 200달러 선결제, 월 17달러꼴). 2026-11-14 요금제 페이지 기준. 원화 금액과 세금은 결제 화면을 따른다
- 들어 있는 파일: 입력값 12개 안팎, 안내 문서(CLAUDE.md) 템플릿 1개, 권한 모드 고르는 표 1개, 오류 문구별 대처표 1개
- 돈 낼 이유 넷 중 셋:
  - 파일: 복사해 쓰는 입력값, 안내 문서 템플릿, 대처표
  - 완주 설계: 설치 → 연습 폴더 → 권한 → 계획 → 실행과 기록 → 규칙 문서 → 내 폴더. 장마다 화면에 남는 것이 하나씩 있다
  - 막히는 지점: 유료 요금제 안내 창, 폴더 선택, 권한을 묻는 창, 이름 바꾸기는 되감기로 돌아오지 않는 점, 사용량 한도
  - 정리: 터미널, 깃, 플러그인 같은 것은 빼고 비개발자가 첫 결과물을 얻는 데 필요한 것만 고른 순서
- 같은 주제의 다른 99BOOKS 책과 겹치지 않는 점: A-06(스킬 하나 만들기)은 채팅에서 쓰는 스킬 하나를 만든다. 이 책은 내 컴퓨터의 폴더를 직접 다루는 Code 탭의 전체 과정이다. A-01(업무 시스템)은 채팅 쪽 프로젝트·스킬·커넥터를 다루고 파일 작업은 다루지 않는다

## 시트의 가안과 달라진 점
- 터미널 설치(윈도우·맥 명령어)를 빼고 데스크톱 앱 Code 탭으로 바꿨다. 공식 문서에서 데스크톱 앱은 Node.js나 CLI 설치가 필요 없다고 확인했다(사용자 결정, 2026-11-14).
- 결과물을 "폴더 정리" 하나로 좁혔다(사용자 결정, 2026-11-14). 엑셀 합치기는 뺐다.
- "되돌리기"는 되감기 기능이 아니라 연습용 폴더와 변경 기록표로 다룬다. 이름 바꾸기·옮기기는 되감기로 돌아오지 않는다고 공식 문서에 적혀 있다.
