# 계획대로 정리하고 변경 기록을 남겨요

## 이 장을 마치면

연습 폴더가 문서, 표, 그림 세 폴더로 나뉘고, 파일 이름이 규칙대로 바뀌어요. 바꾼 내용을 한 줄씩 적은 `변경기록.csv`가 남고, 그 기록으로 파일 하나를 원래대로 돌려 봐요.

## 먼저 알아둘 것

4장에서 받은 계획을 승인하면 계획 모드가 끝나고 실제로 파일을 옮기기 시작해요. 공식 안내에 따르면 승인하는 답은 두 갈래예요. 바뀌는 것을 하나씩 확인하며 진행하는 답과, 확인 없이 진행하는 답이에요. 계획을 더 고치고 싶으면 승인하지 않고 계속 계획하는 답을 골라요.

연습 폴더에서는 확인 없이 진행하는 답을 골라요. 하나씩 확인하는 답을 고르면 파일 20개를 옮기고 이름을 바꿀 때마다 허락 창이 떠요. 계획을 이미 점검했고 가짜 파일뿐이라, 하나씩 확인하는 것보다 끝난 결과를 한 번에 점검하는 편이 빨라요.

확인 없이 진행하는 답을 고르면 권한 모드가 자동으로 바뀌어요. 공식 안내에 따르면 자동 모드를 쓸 수 있는 계정이면 "자동"으로, 쓸 수 없으면 "편집 자동 수락"으로 바뀌어요. 둘 다 작업 폴더 안의 파일 옮기기와 이름 바꾸기를 묻지 않고 해요.

변경 기록을 남기는 이유는 되돌리기 때문이에요. 클로드 코드에는 대화를 앞 시점으로 되감는 기능이 있어요. 그런데 공식 안내에 따르면 명령으로만 옮기거나 이름을 바꾼 파일은 되감기로 돌아오지 않아요. 폴더 정리는 대부분 이런 명령으로 이뤄져요.

그래서 이 책은 되감기 대신 변경 기록표를 써요. 원래 이름과 새 이름이 한 줄씩 적혀 있으면, 어떤 파일이든 그 줄을 보고 원래대로 돌릴 수 있어요. 중간에 멈췄을 때도 어디까지 했는지 이 표로 알 수 있어요.

기록 파일 자체는 옮기지 않게 해야 해요. `변경기록.csv`도 이름이 `.csv`로 끝나서, 규칙대로라면 "표" 폴더로 들어가 버려요. 이 장의 입력값에 "옮기지 말 파일"을 적는 이유예요.

## 따라 하기

### 1. 4장의 세션으로 돌아가요

사이드바의 지난 대화 목록에서 4장에서 계획표를 받은 세션을 열어요. 권한 모드 칸에 "계획"이 보이고, 계획표가 대화창에 남아 있으면 돼요.

세션을 찾지 못하면 연습 폴더를 계획 모드로 새로 열고, 4장 입력값 5를 다시 보내 계획을 받아요. 4장의 점검을 한 번 더 하고 이 장으로 돌아와요.

### 2. 실행 순서를 정해 줘요

계획을 승인하기 전에, 같은 세션에 아래 입력값을 보내요. 실행 순서와 옮기지 말 파일을 계획에 더하는 요청이에요.

```입력값 7
계획에 아래 실행 순서를 더해줘. 아직 실행하지 마.
1. 먼저 변경기록.csv를 만들고 계획표 전체를 적어. 바꾼 시각 칸은 비워 둬.
2. 파일을 하나 옮길 때마다 그 줄의 바꾼 시각을 채워.
3. 변경기록.csv는 어디로도 옮기지 말고 이 폴더 맨 위에 둬.
4. 변경기록.csv는 엑셀에서 한글이 깨지지 않게 UTF-8 BOM으로 저장해.
5. 다 끝나면 옮긴 파일 수와 옮기지 못한 파일 수를 알려줘.
```

마이크로소프트 도움말에 따르면 엑셀은 BOM을 붙여 저장한 UTF-8 CSV를 바로 열 수 있어요. BOM은 파일 맨 앞에 붙는 보이지 않는 표시예요. 이 표시가 없으면 엑셀에서 한글이 깨져 보일 수 있어요.

### 3. 계획을 승인해요

클로드 코드가 고친 계획을 다시 보여주고 진행 방법을 물으면, 확인 없이 진행하는 답을 골라요. 계획 모드가 끝나고 권한 모드 칸이 바뀌면서 정리가 시작돼요.

대화창에 파일을 옮기는 과정이 차례로 보여요. 다 끝나면 옮긴 파일 수와 옮기지 못한 파일 수를 알려줘요. 옮긴 수가 20이고 옮기지 못한 수가 0이면 다음 단계로 가요.

진행 중에 허락 창이 뜰 때도 있어요. 파일 옮기기 말고 다른 명령을 쓰려고 할 때예요. 3장에서처럼 창의 내용을 읽고, 연습 폴더 안에서 파일을 옮기거나 목록을 보는 명령이면 허락해요. 폴더 밖을 건드리거나 지우는 명령이면 거절해요.

![정리가 끝난 연습 폴더와 맨 위에 남은 변경기록.csv](/books/claude-code-start/ch5-result.svg)

### 4. 결과를 점검해요

파일 탐색기에서 `클로드연습` 폴더를 열어 문서, 표, 그림 세 폴더와 `변경기록.csv`가 보이는지 봐요. 그다음 같은 세션에 아래 입력값을 보내 점검을 맡겨요.

```입력값 8
정리 결과를 점검해줘. 아무것도 바꾸지 마.
- 폴더별 파일 수
- 계획표의 새 이름과 실제 이름이 다른 파일
- 아직 이 폴더 맨 위에 남아 있는 파일 (변경기록.csv 빼고)
- 변경기록.csv에서 바꾼 시각이 비어 있는 줄
결과는 항목마다 "문제 없음" 또는 해당 파일 이름으로 알려줘.
```

네 항목이 모두 "문제 없음"이면 정리는 끝났어요. 문제가 나온 항목은 그 파일만 짚어서 고쳐 달라고 해요.

예를 들어 "계획표와 다른 파일"에 하나가 나왔다면, 4장 입력값 6처럼 그 파일 이름과 원하는 새 이름만 적어서 보내요. 고친 뒤에는 입력값 8을 다시 보내 네 항목이 모두 "문제 없음"이 될 때까지 반복해요.

`변경기록.csv`를 엑셀이나 메모장으로 열어 봐요. 줄마다 원래 이름, 새 위치와 이름, 바꾼 시각이 채워져 있어야 해요. 줄 수가 20이고 빈칸이 없으면 기록도 끝까지 남은 거예요.

### 5. 기록으로 파일 하나를 되돌려 봐요

변경 기록표가 정말 쓸모 있는지 연습 삼아 확인해요. 아래 입력값의 `[ ]`에 `변경기록.csv`에서 아무 줄의 새 이름을 하나 골라 넣어요.

```입력값 9
변경기록.csv를 보고 [되돌릴 파일의 새 이름]만 원래 이름과 원래 위치로 되돌려줘.
되돌린 줄의 바꾼 시각 칸 옆에 "되돌림"이라고 적어줘.
다른 파일은 건드리지 마.
```

파일 탐색기에서 그 파일이 원래 이름으로 폴더 맨 위에 돌아왔는지 봐요. 확인했으면 "방금 되돌린 파일을 다시 계획대로 옮겨줘"라고 보내 정리된 상태로 돌려놓아요.

이 연습을 해 두면 7장에서 진짜 폴더를 정리할 때 덜 망설이게 돼요. 무엇이 잘못돼도 기록을 보고 돌릴 수 있다는 것을 이미 확인했기 때문이에요.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 변경기록.csv가 "표" 폴더로 들어갔어요 | 옮기지 말 파일을 정하지 않았어요 | "변경기록.csv를 폴더 맨 위로 다시 옮겨줘"라고 보내요. 다음부터는 입력값 7의 3번 줄을 꼭 넣어요 |
| 중간에 멈췄어요 | 사용량 한도에 걸렸거나 중지 버튼을 눌렀어요 | "변경기록.csv에서 바꾼 시각이 빈 줄만 계획대로 이어서 해줘"라고 보내요 |
| 엑셀에서 변경기록.csv의 한글이 깨져요 | BOM 없이 저장됐어요 | 메모장으로 열거나, "변경기록.csv를 UTF-8 BOM으로 다시 저장해줘"라고 보내요 |
| 계획에 없던 이름이 생겼어요 | 실행 중에 이름이 겹쳐 클로드 코드가 임의로 바꿨어요 | 입력값 8로 찾아낸 뒤, 그 파일만 원하는 이름으로 바꿔 달라고 해요 |

엑셀에서 열 때는 마이크로소프트 도움말에 나온 다른 방법도 있어요. 데이터 탭의 데이터 가져오기에서 "텍스트/CSV에서"를 고르면, BOM이 없는 파일도 한글이 깨지지 않게 열 수 있어요.

사용량 한도 때문에 멈췄다면, 한도가 다시 채워진 뒤에 이어서 하면 돼요. 남은 사용량을 확인하는 곳은 7장에서 다뤄요. 기록표에 바꾼 시각이 빈 줄이 남아 있으니, 이어서 할 곳을 따로 기억해 둘 필요는 없어요.

## 나쁜 예와 좋은 예

| 구분 | 하는 일 | 결과 |
|---|---|---|
| 나쁜 예 | 계획을 승인하고 끝난 뒤 폴더를 훑어보기만 해요 | 이름 하나가 계획과 달라도 지나치기 쉬워요 |
| 좋은 예 | 입력값 8로 네 가지를 점검하게 하고, 기록 파일을 직접 열어 봐요 | 어긋난 파일을 이름으로 찾아내요 |
| 나쁜 예 | 잘못 바뀐 파일을 되감기로 되돌리려고 해요 | 명령으로 옮긴 파일은 되감기로 돌아오지 않을 수 있어요 |
| 좋은 예 | 변경기록.csv를 보고 그 파일만 되돌려 달라고 해요 | 원래 이름과 위치가 적혀 있어서 정확히 되돌아가요 |

첫 번째 쌍의 차이는 점검을 맡기는 방식이에요. "잘 됐어?"라고 묻는 대신, 무엇을 세고 무엇을 비교할지 정해 주면 답도 정확해져요.

두 번째 쌍의 차이는 기록의 유무예요. 기록이 있으면 되돌리기가 "기억해 내기"가 아니라 "표 보고 따라 하기"가 돼요.

## 점검표

- [ ] 실행 순서와 옮기지 말 파일을 입력값 7로 정했어요
- [ ] 계획을 승인하고, 옮긴 수 20과 옮기지 못한 수 0을 확인했어요
- [ ] 입력값 8의 네 항목이 모두 "문제 없음"이에요
- [ ] 변경기록.csv를 열어 세 칸이 채워진 것을 봤어요
- [ ] 파일 하나를 기록으로 되돌렸다가 다시 정리했어요
