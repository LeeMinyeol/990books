# 정리 계획표를 먼저 받아요

## 이 장을 마치면

연습 폴더의 파일 20개마다 옮길 폴더와 새 이름이 적힌 계획표가 대화창에 남아요. 계획표를 다섯 군데 점검하고 고친 상태로, 실행은 5장으로 넘겨요.

## 먼저 알아둘 것

계획 모드는 클로드 코드가 파일을 읽고 살펴보기만 하고, 고치지는 않은 채 계획을 내놓는 모드예요. 공식 안내에 따르면 계획을 승인하기 전까지 파일을 고치는 일은 막혀 있어요.

계획을 먼저 받는 이유는 고치는 값이 다르기 때문이에요. 계획표의 한 줄은 말 한마디로 고쳐져요. 이미 바뀐 파일 20개는 하나씩 되돌려야 해요.

정리 규칙은 계획을 요청할 때 함께 적어요. 규칙이 없으면 클로드 코드가 그럴듯한 규칙을 스스로 정해요. 그 규칙이 틀린 것은 아니지만 내가 원하는 규칙과는 다를 수 있어요.

## 따라 하기

### 1. 연습 폴더를 계획 모드로 열어요

**새로 만들기**로 새 세션을 열고, 폴더 칸에서 `클로드연습`을 고른 뒤 권한 모드 칸에서 **계획**을 골라요.

성공: 입력 상자 아래 줄의 권한 모드 칸에 "계획"이 보여요.

안 되면: 폴더 칸의 "최근"에 `클로드연습`이 없으면 **폴더 열기…**로 직접 골라요. 2장에서 만든 폴더는 "문서" 폴더 안에 있어요.

공식 안내에 따르면 계획 모드는 지금 세션에만 적용돼요. 새 세션을 열면 이 폴더에 기억된 다른 모드로 돌아가니, 이 장을 하는 동안에는 같은 세션을 계속 써요.

### 2. 정리 규칙과 함께 계획을 요청해요

아래 입력값을 그대로 붙여넣고 보내요. 규칙을 바꾸고 싶으면 "정리 규칙" 아래 줄만 고쳐요.

```입력값 5
이 폴더의 파일을 정리하는 계획을 세워줘. 아직 아무것도 바꾸지 마.

정리 규칙:
- 하위 폴더: 메모(.txt)는 "문서", 표(.csv)는 "표", 그림(.svg)은 "그림"
- 새 이름: 날짜_내용_순번 (예: 2026-11-03_회의메모_01.txt)
- 날짜는 파일 이름에 있는 날짜를 YYYY-MM-DD로 바꿔 써. 날짜가 없으면 "날짜없음"
- "최종", "수정", "(2)" 같은 말은 새 이름에서 빼
- 새 이름에는 < > : " / \ | ? * 를 쓰지 말고, 끝에 공백이나 마침표를 두지 마

계획은 표로 보여줘. 열은 지금 이름 / 옮길 폴더 / 새 이름 / 비고.
새 이름이 겹치거나 내용이 거의 같은 파일은 비고에 적어줘.
실행할 때 바꾼 내용을 "변경기록.csv"에 남기는 단계도 계획에 넣어줘.
변경기록.csv의 열은 원래 이름 / 새 위치와 이름 / 바꾼 시각으로 해줘.
```

성공: 파일을 하나씩 읽는 과정이 지나간 뒤, 열이 네 개인 계획표가 나와요.

안 되면: 표 대신 긴 글로 나오면 "계획을 표로 다시 보여줘. 열은 지금 이름 / 옮길 폴더 / 새 이름 / 비고"라고 보내요.

안 되면: 계획을 요청했는데 파일이 바로 바뀌었다면 권한 모드가 계획이 아니었던 거예요. 연습 폴더라면 2장 입력값 1로 다시 만들고 처음부터 해요.

이 장에서 쓰는 규칙은 세 가지예요. 종류별로 폴더를 나누고, 이름을 "날짜_내용_순번" 모양으로 맞추고, 윈도우에서 파일 이름에 쓸 수 없는 글자는 빼요. 마이크로소프트 문서에 따르면 `< > : " / \ | ? *` 아홉 글자는 파일 이름에 쓸 수 없어요. 이름 끝에 공백이나 마침표를 두는 것도 피해야 해요.

이름을 날짜로 시작하게 하면 파일 탐색기에서 이름순으로 정렬할 때 날짜순으로 줄을 서요. 끝에 붙는 순번은 같은 날 같은 내용의 파일이 둘 이상일 때 이름이 겹치지 않게 해 줘요.

변경 기록은 `변경기록.csv`라는 표 파일로 남겨요. 엑셀이나 구글 시트, 메모장으로 열 수 있어요. 5장에서 이 표가 있어야 잘못 바뀐 파일을 원래대로 돌릴 수 있어요.

표 아래에 계획대로 진행할지 묻는 창이 함께 뜰 수 있어요. 이번 장에서는 승인하지 않아요. 계속 계획하는 답을 고르거나, 창을 그대로 두고 다음 단계의 점검부터 해요.

### 3. 계획표를 다섯 군데 점검해요

계획표를 위에서부터 읽으며 아래 다섯 가지를 확인해요.

1. **줄 수**가 20줄인가요? 빠진 파일이 있으면 그 파일은 정리되지 않고 남아요.
2. **새 이름이 겹치는 줄**이 있나요? 같은 폴더에 같은 이름이 둘이면 하나가 다른 하나를 덮어쓸 수 있어요.
3. **날짜 모양**이 모두 YYYY-MM-DD인가요? "11월 3일"처럼 남은 줄이 없는지 봐요.
4. **쓸 수 없는 글자**가 새 이름에 남아 있나요? 특히 원래 이름에 콜론(:)이 있던 파일을 봐요.
5. **비고**에 표시된 파일을 어떻게 할지 정했나요? 내용이 거의 같은 두 파일은 둘 다 남길지 하나만 남길지 정해요.

![계획표에서 새 이름이 같은 두 줄을 찾는 모습](/books/claude-code-start/ch4-plan-check.svg)

성공: 다섯 가지 모두 괜찮으면 4단계를 건너뛰고 5단계로 가요.

안 되면: 계획표가 20줄보다 많거나 적으면 2장 입력값 2로 받은 파일 목록 표와 나란히 놓고 대조해요. 빠지거나 더해진 파일이 바로 보여요.

점검은 두 번에 나눠 읽으면 빨라요. 처음에는 표를 위에서 아래로 한 번 읽으며 줄 수와 비고를 봐요. 그다음 새 이름 열만 따로 읽으며 겹치는 이름, 날짜 모양, 쓸 수 없는 글자를 봐요.

비고에 "내용이 거의 같음"이라고 나온 두 파일은 이 책에서는 둘 다 남겨요. 지우기는 되돌리기 어려운 일이라, 연습 단계에서는 계획에 넣지 않는 편이 안전해요.

### 4. 고칠 줄만 짚어서 고쳐 달라고 해요

고칠 줄만 아래 입력값으로 보내요. `[ ]` 두 곳을 채우면 돼요.

```입력값 6
계획표에서 아래 줄만 고쳐줘. 나머지 줄은 그대로 둬.
- [고칠 줄의 지금 이름]: [어떻게 바꿀지]
고친 뒤에는 바뀐 줄만 다시 보여줘. 아직 실행하지 마.
```

```작성 예시
계획표에서 아래 줄만 고쳐줘. 나머지 줄은 그대로 둬.
- 회의메모 최종(2).txt: 새 이름 순번을 02로 바꿔줘
고친 뒤에는 바뀐 줄만 다시 보여줘. 아직 실행하지 마.
```

성공: 고친 줄만 다시 나오고, 3단계의 다섯 가지에 걸리는 줄이 없어요.

안 되면: 다른 줄까지 바뀌었다면 "나머지는 그대로 둬"가 빠진 거예요. 입력값 6을 그대로 다시 보내요.

작성 예시는 새 이름이 겹친 두 줄 가운데 하나의 순번을 바꾸는 요청이에요. 01과 02로 나뉘면 두 파일이 같은 폴더에 함께 있을 수 있어요. 고칠 줄이 여러 개면 `-` 줄을 늘려 한 번에 보내요.

계획 전체를 다시 세워 달라고 하지 않는 이유가 있어요. 맞았던 줄까지 새로 바뀌면 점검을 처음부터 다시 해야 해요.

### 5. 계획을 그대로 두고 5장으로 넘어가요

이 세션을 닫지 않고 그대로 둔 채 5장으로 넘어가요.

성공: 대화창에 점검을 마친 계획표가 남아 있고, 권한 모드 칸은 아직 "계획"이에요.

안 되면: 세션을 닫았다면 사이드바의 지난 대화 목록에서 다시 열어요. 찾기 어려우면 입력값 5를 다시 보내 계획을 새로 받아도 돼요.

5장에서는 이 계획을 승인하고 실행해요. 승인하기 전까지 폴더의 파일은 하나도 바뀌지 않아요.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 계획을 요청했는데 파일이 바로 바뀌었어요 | 권한 모드가 계획이 아니었어요 | 모드 칸을 확인해요. 연습 폴더라면 2장 입력값 1로 다시 만들고 처음부터 해요 |
| 표 대신 긴 글로 계획이 나와요 | 표 형식을 요청에서 빠뜨렸어요 | "계획을 표로 다시 보여줘. 열은 지금 이름 / 옮길 폴더 / 새 이름 / 비고"라고 보내요 |
| 고쳐 달라고 했더니 다른 줄까지 바뀌었어요 | "나머지는 그대로 둬"가 빠졌어요 | 입력값 6처럼 고칠 줄과 그대로 둘 줄을 함께 적어요 |
| 계획 중에 명령 실행을 허락해 달라고 해요 | 파일을 살펴보는 데 명령을 쓰려고 해요 | 파일 목록 보기처럼 읽기만 하는 명령이면 허락해도 돼요. 이름 바꾸기나 지우기면 거절해요 |

## 나쁜 예와 좋은 예

| 구분 | 요청 | 결과 |
|---|---|---|
| 나쁜 예 | "이 폴더 깔끔하게 정리해줘" | 폴더 나누는 기준과 이름 규칙을 클로드 코드가 정해서, 내 생각과 다른 계획이 나와요 |
| 좋은 예 | 입력값 5처럼 폴더 기준, 이름 모양, 쓸 수 없는 글자를 적어요 | 규칙대로 나온 계획이라 어긋난 줄만 찾아 고치면 돼요 |
| 나쁜 예 | 마음에 안 드는 줄이 보이면 "다시 계획해줘"라고 보내요 | 맞았던 줄까지 새로 바뀌어서 처음부터 다시 점검해야 해요 |
| 좋은 예 | 입력값 6처럼 고칠 줄만 짚어서 보내요 | 고친 줄만 다시 보면 돼요 |

첫 번째 쌍은 규칙을 누가 정하느냐의 차이예요. 규칙을 내가 정하면 계획표는 그 규칙을 지켰는지만 보면 돼요.

두 번째 쌍은 고치는 범위의 차이예요. 이 장의 입력값 5는 규칙 부분만 바꾸면 다른 폴더에도 그대로 쓸 수 있어요. 6장에서는 이 규칙을 문서로 남겨서 매번 붙여넣지 않아도 되게 해요.

## 점검표

- [ ] 연습 폴더를 계획 모드로 열었어요
- [ ] 입력값 5로 표 모양의 계획을 받았어요
- [ ] 줄 수, 겹치는 이름, 날짜 모양, 쓸 수 없는 글자, 비고를 확인했어요
- [ ] 고칠 줄은 입력값 6으로 고쳤어요
- [ ] 계획을 아직 승인하지 않고 세션을 그대로 뒀어요
