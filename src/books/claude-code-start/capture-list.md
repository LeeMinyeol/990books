# 실제 화면 캡처 목록 (글자 확인용)

2026-11-14 결정 이후 캡처는 책에 넣지 않고, 목업을 정확하게 그리기 위한 확인용으로만 쓴다. 받은 1~6번 내용은 `outline.md`에 적었다.

캡처는 윈도우 캡처 도구(**Win + Shift + S**)로 찍어 채팅창에 붙여넣으면 돼요.
사이드바의 다른 대화·세션 이름, 계정 이메일과 이름은 보이지 않게 잘라 주세요(가려도 돼요).

| # | 어디서 | 무엇이 보이게 | 쓰는 곳 |
|---|---|---|---|
| 1 | Code 탭을 처음 연 화면 | 왼쪽 사이드바, 가운데 입력 상자, 상자 아래 줄의 버튼들이 한 화면에 | 1장 "Code 탭을 열어요" |
| 2 | 사이드바 위쪽 | Code 탭 글자(또는 아이콘)가 크게 보이게 | 1장, 표지 설명 |
| 3 | 입력 상자 아래 줄의 첫 번째 버튼(환경)을 누른 상태 | 펼쳐진 목록의 글자 | 2장 "연습 폴더를 열어요" |
| 4 | 그 옆 폴더 버튼을 누른 상태 | "폴더 열기"에 해당하는 메뉴 글자 | 2장 |
| 5 | 모드 버튼을 누른 상태 | 권한 모드 목록의 이름 네 가지 | 3장 "권한 창을 읽어요" |
| 6 | 맨 위 메뉴의 Help(도움말) | About Claude, Check for Updates에 해당하는 글자 | 1장 "앱 버전을 적어 둬요" |

- 로그인 화면은 찍지 않아도 돼요. 로그아웃해야 볼 수 있어서 목업으로 둘게요.
- 화면이 한국어인지 영어인지에 따라 책의 버튼 글자를 맞출게요. 지금 원고는 공식 문서의 이름(Code, Help → About Claude)으로 썼어요.
