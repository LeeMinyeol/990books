# 홈 화면 설계 (2026-11-10)

상태: **구현 완료(2026-11-10)**. 구현하면서 바꾼 점: 분야 칩은 가로 스크롤 대신 줄바꿈, "990원" 도장은 표지 오른쪽 아래. 와이어프레임은 [wireframe.md](wireframe.md) 3-1에 있어요.

## 왜 만드나
지금 홈은 책 제목 목록뿐이에요. 처음 온 사람이 "어떤 결과물을 만들 수 있는지"를 이미지로 먼저 보고 책을 고르게 하는 것이 목적이에요.

## 목표 / 하지 않는 것
- 목표: 헤더 → 히어로 캐러셀 → 분야 칩 → 3열 카드 그리드. PC·모바일 반응형. 책을 데이터에 추가하면 홈에 자동 반영.
- 이번에 하지 않는 것: 책 상세 페이지, 로그인 기능, 검색, 결제, 후기 평점 데이터(자리만).
- 실패로 보는 것: 큐레터와 헷갈리는 외형(노랑·검정, 로고 모양, 문구), 수익·성공 보장 문구, 모바일에서 느려지는 연출.

## 확정된 결정 (2026-11-10, 사용자 확인)
1. 아직 없는 책 2·3권은 "준비 중" 카드로 노출하고 열리지 않게 한다.
2. 로고는 Black Han Sans 글자 로고 "990books", 사이트 바탕은 흰색·검정 중립.
3. 이번엔 홈만. 카드 클릭은 뷰어로 임시 연결.
4. 로그인 버튼은 자리만(누르면 "준비 중" 안내), 검색은 숨김.

## 디자인 방향
한 문장: **가게 진열대처럼 조용한 흰 바탕에, 책마다 자기 색을 가진 표지가 놓이고, "990원" 가격 도장 하나만 눈에 띄게.**

- 색
  - 종이 `#FFFFFF`, 잉크 `#111111`, 보조 글 `#6B6B6B`, 선 `#E5E5E5`
  - 책 포인트컬러: 책 데이터의 값(인스타 책 `#E8436E`). 히어로 배경과 카드 강조선에만 사용
  - 준비 중인 책: 포인트컬러 없이 회색(책 색은 그 책을 만들 때 정함)
- 글자: 로고·책 제목은 Black Han Sans, 나머지는 Pretendard. 새 폰트 추가 없음
- 눈에 띄는 요소는 하나: 히어로의 "990원" 도장. 뷰어의 완독 스탬프와 같은 원형 도장 모양을 써서 사이트 전체가 한 벌로 보이게 함
- 정렬: 전부 왼쪽 정렬. 큐레터의 가운데 로고·검정 헤더는 쓰지 않고, 흰 헤더에 로고 왼쪽·로그인 오른쪽
- 움직임: 캐러셀 넘김 한 가지만. 카드마다 떠오르는 효과나 스크롤 등장 효과는 넣지 않음. 모션 줄이기 설정 존중
- 피한 것: 카드마다 같은 그림자, 장식용 그라데이션, 영문 대문자 라벨

## 만드는 방법
방법은 사실상 한 가지예요. 이미 쓰고 있는 Next.js + Tailwind 안에서 새 라이브러리 없이 만들어요.
- 캐러셀: 브라우저 기본 가로 스크롤 스냅(CSS scroll-snap) + 화살표 버튼. 캐러셀 라이브러리(Embla, Swiper)는 책 3권 규모에 과해서 제외
- 분야 필터: 화면 안에서만 바뀌는 상태. 주소(URL)에 분야를 넣는 방식은 분야가 2개 이상이 되면 다시 검토
- 데이터: `src/lib/book.ts`의 Book에 분야(category), 표지 이미지(cover), 한 줄 소개(summary)를 추가. 준비 중인 책은 `src/books/coming.ts`에 제목·분야만 가진 가벼운 목록으로 둠
- 컴포넌트: `src/components/home/` 아래 SiteHeader, HeroCarousel, CategoryChips, BookCard

## 내가 정한 것 (확인 필요)
- 준비 중 책의 표시 제목(가제): "스마트스토어 상세페이지, 클로드로 한 번에 만들기"(1권 다음편 카드와 동일), "유튜브 쇼츠 자동화"(제목 미정이라 주제만 표시)
- 히어로 버튼 문구: "이 책 보기"
- 푸터 문구: "모든 책 990원, 결제 후 계속 볼 수 있어요"
- 분야 칩은 책이 있는 분야만 표시(지금은 전체보기, AI)
- 썸네일 비율: 슬라이드 이미지와 같은 16:10
