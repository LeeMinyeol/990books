# 앱을 설치하고 Code 탭을 열어요

## 이 장을 마치면

내 컴퓨터에 Claude 데스크톱 앱이 설치되고, 왼쪽 사이드바에서 Code 탭이 열려 있어요. 다음 장부터는 이 화면에서 바로 시작해요.

## 먼저 알아둘 것

클로드 코드는 AI가 내 컴퓨터의 폴더 안에서 파일을 직접 읽고, 만들고, 고치는 도구예요. 채팅창의 클로드는 내가 붙여넣은 글만 볼 수 있어요. 클로드 코드는 내가 고른 폴더 안의 파일을 열어 보고 바꿀 수 있어요.

클로드 코드를 쓰는 방법은 크게 두 가지예요. 하나는 검은 화면(터미널)에 명령어를 입력해서 설치하는 방법이에요. 다른 하나는 Claude 데스크톱 앱의 Code 탭을 쓰는 방법이에요.

이 책은 데스크톱 앱으로 시작해요. 공식 안내에 따르면 데스크톱 앱에는 클로드 코드가 들어 있어서, 따로 프로그램을 더 설치하지 않아도 Code 탭을 쓸 수 있어요. 명령어를 몰라도 버튼과 대화창만으로 따라올 수 있어요.

Code 탭은 유료 요금제에서만 열려요. 개인이라면 가장 낮은 유료 요금제인 Pro부터 쓸 수 있고, Max·Ultra와 회사용 Team·Enterprise에서도 열려요. 무료 계정으로 Code 탭을 누르면 유료 요금제를 구독하라는 안내가 먼저 나와요.

Pro 요금제는 월 결제로 20달러예요. 1년 치를 한 번에 내면 200달러이고, 한 달로 치면 17달러쯤이에요. 2026년 11월 14일 Claude 요금제 페이지 기준이고, 원화 금액과 세금은 결제 화면에서 확인해요.

유료 요금제도 쓸 수 있는 양에 한도가 있어요. Pro 요금제 안내에는 사용량이 5시간 단위와 1주 단위로 정해진다고 적혀 있어요. 이 책의 연습은 작은 폴더 하나로 하기 때문에 한도를 크게 쓰지 않아요.

이 책을 다 따라 하면 "정리해줘" 한마디로 다시 돌릴 수 있는 폴더 정리가 남아요. 1장은 앱을 여는 데까지, 2장부터 7장은 연습 폴더를 정리하고 그 규칙을 문서로 남기는 순서예요. 장마다 화면에 남는 것이 하나씩 있어서, 어디까지 했는지 바로 알 수 있어요.

클로드 코드가 손대는 범위는 내가 고른 폴더 하나예요. 폴더를 고르지 않으면 아무 파일도 건드리지 않아요. 그래서 이 책은 처음부터 끝까지 일부러 만든 연습 폴더에서 시작해요.

## 따라 하기

### 1. 내 컴퓨터가 설치 조건에 맞는지 확인해요

맥은 macOS 13(Ventura)부터, 윈도우는 Windows 10부터 데스크톱 앱을 설치할 수 있어요.

내 컴퓨터의 운영체제 버전을 모르면 설치 전에 먼저 확인해요. 조건보다 낮은 버전이면 앱이 설치되지 않아요.

윈도우 컴퓨터 가운데 ARM 프로세서를 쓰는 기종은 설치 파일이 따로 있어요. 공식 안내는 Windows ARM64용 설치 프로그램을 별도로 받으라고 적어요.

### 2. 설치 파일을 내려받아요

브라우저에서 `claude.ai/download`를 열어요. 내 운영체제에 맞는 버전을 골라 다운로드를 눌러요.

### 3. 설치하고 로그인해요

내려받은 파일을 열어 설치를 마쳐요. 윈도우는 시작 메뉴에서, 맥은 응용 프로그램 폴더에서 Claude를 실행해요.

처음 실행하면 로그인 화면이 나와요. 평소 Claude 채팅에 쓰던 계정으로 로그인해요. 유료 요금제를 쓰는 계정이어야 해요.

계정이 여러 개라면 요금제를 결제할 때 쓴 계정으로 로그인해요. 결제하지 않은 계정으로 로그인하면 무료 계정과 같아서, Code 탭을 누를 때 요금제 안내가 나와요.

### 4. Code 탭을 열어요

왼쪽 사이드바 맨 위에 아이콘 두 개가 나란히 있어요. 말풍선 모양은 채팅이고, 그 오른쪽의 **</> 모양 아이콘**이 Code 탭이에요. 눌러요.

![앱 전체 화면에서 사이드바 맨 위를 확대하면, 말풍선 오른쪽의 </> 아이콘이 Code 탭이에요](/books/claude-code-start/ch1-code-tab.mp4)

Code 탭이 열리면 화면 아래쪽에 "작업을 설명하거나 질문하세요"라고 적힌 입력 상자가 보여요. 상자 아래 줄에는 "이 컴퓨터", 폴더 이름, 모델 이름, "자동" 같은 칸이 있어요. 이 칸들은 다음 장부터 하나씩 써요.

![Code 탭 아래쪽의 입력 상자와 그 아래 줄의 칸들](/books/claude-code-start/ch1-input.svg)

사이드바에는 새로 만들기, 검색 같은 메뉴와 지난 대화 목록이 있어요. 채팅으로 돌아가려면 말풍선 아이콘을 누르면 돼요. 이 책은 Code 탭만 써요.

### 5. 앱 버전을 적어 둬요

나중에 화면이 이 책과 다르게 보이면 버전부터 확인해요. 윈도우는 앱 왼쪽 위의 **≡ 메뉴 → 도움말 → Claude 정보**를 눌러요. 맥은 화면 맨 위 메뉴 막대의 Claude 메뉴에서 같은 항목을 찾아요.

![≡ 메뉴의 도움말 안에 있는 업데이트 확인과 Claude 정보](/books/claude-code-start/ch1-help-menu.svg)

버전 번호를 누르면 클립보드에 복사돼요. 메모장에 붙여넣어 적어 둬요. 이 책은 2026년 11월 화면을 기준으로 썼어요.

Code 탭 안의 클로드 코드는 데스크톱 앱이 알아서 내려받고 업데이트해요. 앱만 최신으로 두면 되고, 클로드 코드를 따로 업데이트할 필요는 없어요. 공식 안내에 따르면 맥과 윈도우에서는 앱을 시작할 때 업데이트가 자동으로 설치돼요.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| </> 아이콘을 누르면 요금제 안내 창이 떠요 | 무료 요금제 계정이에요 | 유료 요금제를 구독한 뒤 다시 눌러요. 이미 구독 중이면 구독한 계정으로 로그인했는지 확인해요 |
| 온라인 로그인을 하라는 창이 떠요 | 앱의 로그인이 끝나지 않았어요 | 브라우저에서 로그인을 마치고 앱을 다시 시작해요 |
| `Error 403` 같은 인증 오류가 나요 | 로그인 정보가 꼬였거나 구독이 끝났어요 | 앱 메뉴에서 로그아웃했다가 다시 로그인해요. 그래도 같으면 창만 닫지 말고 앱을 완전히 종료한 뒤 다시 열어요 |
| 앱이 열리는데 화면이 비어 있어요 | 업데이트가 아직 끝나지 않았을 수 있어요 | 앱을 다시 시작해요. 윈도우와 맥은 시작할 때 자동으로 업데이트돼요 |

사이드바 맨 위에 </> 아이콘이 아예 없으면 앱이 오래된 버전일 수 있어요. 윈도우는 **≡ 메뉴 → 도움말 → 업데이트 확인…**으로 업데이트해요. 맥은 메뉴 막대의 Claude 메뉴에 같은 항목이 있어요.

여러 증상이 겹치면 이 순서로 하나씩 확인해요. 먼저 로그인한 계정의 요금제, 다음은 로그아웃 후 다시 로그인, 그다음은 앱을 완전히 종료하고 다시 열기, 마지막은 업데이트예요. 앞에서 해결되면 뒤는 건너뛰어요.

회사 컴퓨터라면 보안 설정 때문에 앱이 연결되지 않을 수 있어요. 이럴 때는 혼자 설정을 바꾸지 말고 회사 전산 담당자에게 물어요.

## 나쁜 예와 좋은 예

| 구분 | 하는 일 | 결과 |
|---|---|---|
| 나쁜 예 | 영상 속 설치 명령어를 복사해서 검은 화면에 붙여넣어요 | 오류 문구가 나와도 무슨 뜻인지 몰라 멈춰요 |
| 좋은 예 | 데스크톱 앱 설치 파일을 받아 실행하고 </> 아이콘을 눌러요 | 명령어 없이 Code 탭까지 와요 |
| 나쁜 예 | 무료 계정으로 로그인한 뒤 Code 탭이 왜 안 되는지 검색해요 | 요금제 문제인지 오류인지 구분하지 못해요 |
| 좋은 예 | 로그인 전에 쓰는 계정의 요금제부터 확인해요 | 안내 창이 떠도 이유를 바로 알아요 |

첫 번째 예에서 달라진 것은 설치 방법이에요. 터미널 방식은 따로 설치하는 과정이 있고, 데스크톱 앱은 그 과정이 앱 안에 들어 있어요.

두 번째 예는 순서의 차이예요. 요금제를 먼저 확인하면 막혔을 때 살펴볼 곳이 하나 줄어요.

## 점검표

- [ ] 내 운영체제가 macOS 13 이상 또는 Windows 10 이상이에요
- [ ] 유료 요금제를 쓰는 계정으로 로그인했어요
- [ ] 사이드바 맨 위의 </> 아이콘으로 Code 탭을 열었어요
- [ ] 앱 버전을 메모장에 적어 뒀어요
