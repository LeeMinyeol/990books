# 990books 와이어프레임 (저충실도 + 주석)

규칙: 회색·검정만 사용, `[ ]`는 버튼, `▒▒▒`는 이미지, `~~~`는 글. 번호 ①②는 콘텐츠 우선순위예요.
충실도 단계: 지금은 **Low-fi → 뷰어는 이미 Mid-fi 구현됨**. 나머지 화면은 아래 Low-fi가 기준이에요.

## 1. 사이트맵

```
홈(책 목록)
├─ 책 상세 ─ (결제) ─ 뷰어
├─ 로그인 (구글·카카오·이메일)          ← 미구현
├─ 내 서재 / 나의 기록                  ← 미구현
└─ 후기 관리(관리자)                    ← 미구현
뷰어(구현됨): 표지 → 준비물 → 본문 → 요약 → 다음편 카드
```

## 2. 사용자 흐름

```
[홈에서 책 카드 선택] → [책 상세: 미리보기·난이도·후기]
      → <로그인했나요?> ─아니오→ [로그인] ┐
                         └예───────────────┤
      → [결제 화면: 환불 규정 고지(열람 전만 환불)] → [결제]
      → [뷰어: 표지 → ... → 마지막 장] → 완독 스탬프
      → <다음편 구매?> ─예→ [다음편 결제]   └아니오→ [내 서재]
재방문: [내 서재] → [이어보기] → 마지막 본 장에서 시작
```

## 3. 화면별 와이어프레임

### 3-1. 홈 (2026-11-10 개정, 구조 레퍼런스: 큐레터)

PC (1024px 이상)
```
┌──────────────────────────────────────────────────────────┐
│ 990books                                      [로그인]   │ ① 상단 고정 헤더
├──────────────────────────────────────────────────────────┤
│ ┌───────────────────────┐                                │
│ │▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│   책 제목(크게)        (990원) │ ② 히어로 캐러셀
│ │▒▒▒ 결과물 이미지 ▒▒▒▒▒│   ~~~ 한 줄 소개 ~~~           │   배경: 그 책의 포인트컬러
│ │▒▒▒▒▒▒ 16:10 ▒▒▒▒▒▒▒▒▒▒│   도구·비용 / 시간·장수        │
│ └───────────────────────┘   [이 책 보기]                 │
│                                           [←] 1 / 3 [→]  │
├──────────────────────────────────────────────────────────┤
│ [전체보기] [AI]                                          │ ③ 분야 칩(선택된 칩 강조)
│ ┌──────────┐  ┌──────────┐  ┌──────────┐                 │
│ │▒▒ 이미지 │  │▒ 준비 중 │  │▒ 준비 중 │                 │ ④ 3열 카드 그리드
│ │ 제목     │  │ 제목     │  │ 제목     │                 │
│ │ 도구·비용│  │ 준비 중  │  │ 준비 중  │                 │
│ │ 시간·장수│  │          │  │          │                 │
│ │ ★평점    │  │          │  │          │                 │
│ └──────────┘  └──────────┘  └──────────┘                 │
├──────────────────────────────────────────────────────────┤
│ 990books · 모든 책 990원, 결제 후 계속 볼 수 있어요      │ ⑤ 푸터
└──────────────────────────────────────────────────────────┘
```

모바일 (375px)
```
┌────────────────────┐
│ 990books  [로그인] │ ①
├────────────────────┤
│ ▒▒▒ 이미지 ▒▒▒▒▒▒▒ │ ② 이미지 위, 글 아래
│ 책 제목     (990원)│   좌우 스와이프로 넘김
│ ~~~ 한 줄 소개 ~~~ │
│ [이 책 보기]       │
│        [←] 1/3 [→] │
├────────────────────┤
│ [전체보기][AI]     │ ③ 칩은 넘치면 줄바꿈
│ ┌────────────────┐ │
│ │▒▒ 이미지       │ │ ④ 카드 1열(태블릿 2열)
│ │ 제목           │ │
│ │ 도구·비용      │ │
│ │ 시간·장수      │ │
│ └────────────────┘ │
└────────────────────┘
```

주석
- 헤더: 로고 클릭 = 홈. 로그인 버튼은 자리만 두고, 누르면 "로그인은 준비 중이에요" 안내. 검색은 책이 늘어날 때까지 숨김.
- 캐러셀: 자동 넘김 없음. 화살표 / 스와이프 / 키보드 ← →. "1 / 3" 표시. 준비 중인 책은 버튼 대신 "준비 중이에요" 표시.
- 카드 정보 순서 고정: 필요 도구·추가 비용 → 소요시간·슬라이드 수 → 완독자 후기 평점(후기 3개 이상부터 표시).
- 난이도는 카드에 넣지 않고 상세에 표시. 카드 전체가 하나의 링크(터치 영역 전체).
- 카드 클릭: 공개된 책은 뷰어로 임시 연결(책 상세 페이지는 결제 단계에서 추가). 준비 중 카드는 열리지 않음.
- 가격: 카드마다 반복하지 않고 히어로의 "990원" 도장과 푸터 한 줄로만 표시.

상태
| 상태 | 화면 동작 |
|---|---|
| 책 1권 + 준비 중 2권(현재) | 캐러셀 1/3, 그리드 3칸 |
| 선택한 분야에 책 없음 | "이 분야의 책을 준비하고 있어요" 안내 |
| 표지 이미지 없음 | 포인트컬러 바탕에 제목만 표시 |
| 후기 3개 미만 | 평점 줄을 그리지 않음 |

### 3-2. 책 상세
```
┌──────────────────────┐
│ ▒▒▒ 표지·결과물 ▒▒▒ │ ①
│ 책 제목              │ ②
│ 난이도 · 소요시간    │ ③
│ ~~~ 이런 분께 ~~~    │ ④
│ ~~~ 목차(장 요약) ~~~│ ⑤
│ 후기(승인된 것만)    │ ⑥
├──────────────────────┤
│ 990원  [결제하기]    │ ⑦ 하단 고정
│ 열람 전 환불 가능    │   사전 고지 문구
└──────────────────────┘
```
주석: 환불 규정은 결제 버튼 바로 위·아래에 항상 노출. 법적 적용은 별도 확인.

### 3-3. 뷰어 (구현됨)
```
PC 16:9 프레임                      모바일 세로 전체
┌────────────────────────────┐     ┌────────────────┐
│ 책 제목          5/12 · 42%│ ①   │ 제목    5/12·42%│
│ ▓▓▓▓▓▓▓░░░░░░░░ 진행 막대  │     │ ▓▓▓▓░░░░        │
│                            │     │                 │
│  STEP 3                    │ ②   │ STEP 3          │
│  제목                      │     │ 제목            │
│  ~~~ 한 줄 설명 ~~~        │ ③   │ ~~~ 설명 ~~~    │
│  ┌ 입력값 1        [복사] ┐│ ④   │ ┌ 입력값 [복사]┐│
│  └ ~~~ 프롬프트 ~~~       ┘│     │ └ ~~~ ~~~      ┘│
│ [← 이전]  안내   [다음 →]  │ ⑤   │ [←이전]  [다음→]│
└────────────────────────────┘     └────────────────┘
```
주석(인터랙션):
- 넘기기: 버튼 / 키보드 ← → / 모바일 좌우 스와이프. 오른쪽·왼쪽 = 다음·이전으로 고정.
- 진행률: 장이 바뀔 때마다 즉시 갱신. 완독 = 마지막 장 도달.
- 복사: 누르면 1.6초간 "복사됨". 클립보드 권한이 없으면 대체 복사.
- 접근성: 터치 영역 44px 이상, 진행 막대에 role=progressbar, 모션 줄이기 설정 존중.

### 3-4. 완독/다음편 장 (구현됨)
```
┌────────────────────────────┐
│ 다음편 예고        ( 완독 )│ ② 스탬프(구매자 기록)
│ ┌────────────────────────┐ │
│ │ 🔒 잠겨 있어요         │ │ ① 잠금 카드(반짝임)
│ │ 다음 책 제목           │ │
│ │ 한 줄 소개             │ │
│ │ 990원 [결제하기]       │ │ ③ 결제 연결 전엔 비활성
│ └────────────────────────┘ │
│ ← 이전              [처음으로]│
│ (후기 남기기: 완독자만, 관리자 승인 후 등록) ← 미구현
└────────────────────────────┘
```

## 4. 상태 목록 (뷰어)

| 상태 | 화면 동작 | 구현 |
|---|---|---|
| 첫 방문 | 표지부터 시작 | ✅ |
| 이어보기 | "N장에서 이어서 볼게요 [처음부터]" 알림, 넘기면 사라짐 | ✅ |
| 완독 후 재방문 | 처음부터 열림 (스탬프 기록은 유지) | ✅ |
| 저장소 사용 불가 | 기록 없이 동작 (오류 없음) | ✅ |
| 이미지 없음 | "스크린샷 자리" 대체 박스 | ✅ |
| 로딩 중 | 저장값을 읽기 전엔 슬라이드를 그리지 않음 | ✅ |
| 미구매 접근 | 책 상세로 안내 | ⬜ (결제 단계) |
| 다음편 구매 후 | 잠금 해제 모션 | ⬜ (결제 단계) |

## 5. 반응형 규칙
- 1024px 이상: 16:9 프레임(최대 1100px), 이미지와 글을 좌우 2열.
- 1024px 미만: 화면 전체 세로. 이미지가 위, 글이 아래.
- 이미지 비율은 16:10 고정, 슬라이드당 200KB 이하.
