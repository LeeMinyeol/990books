# 전자책·가이드 사례 분석 (2026-11-10)

전용 스킬 3개(콘텐츠 검수, 전자책 제작, 상세페이지 제작)를 만들기 전에 본 사례예요. 구조와 방식만 참고하고, 문구·디자인·내용은 가져오지 않아요.

## 본 범위와 한계
| 사례 | 본 것 | 못 본 것 |
|---|---|---|
| 분양의신 아카데미 | 목록, 상세페이지 2권(상단 정보, 소개 이미지 윗부분, 맛보기 1쪽) | 책 전체 본문(로그인 필요, "Unauthorized"), 소개 이미지 아랫부분 |
| 마공사(클래스유 강의 19705) | 강의 상세페이지 글 전체 | 강의 영상 |
| 게으른빌더 | 첫 화면, 무료 가이드 1편의 구조와 앞부분 | 유료 챌린지 내용 |
| 스레드 무료 전자책 | 검색 결과에 나온 게시글 요약 8건, 배포 페이지 1곳 | 게시글 본문 전체(로그인 필요) |

## 1. 분양의신 아카데미 (전자책 판매)
**구성**
- 목록 카드: 후킹 문장 2줄 + 책 이름, 정가와 할인가, 분야 태그, "누구에게 추천" 태그(팀원추천, 리더추천).
- 상세페이지 순서: 표지 → 제목·부제 → 별점 → 가격 → 해시태그 → 소개문 3~4문장 → 탭(소개 / 잠깐 맛보기 / 별점) → 하단 고정 버튼(장바구니, 선물, 구매).
- 소개문 공식: 독자가 겪는 장면("하루 200콜을 돌리는데 계약은 왜 옆자리에서만 나올까요?") → 원인을 다시 정의 → 책이 주는 것.
- 소개 이미지 윗부분: 표지와 배지 3개 → "이 장면이 낯설지 않다면" 공감 체크 6개 → 문제 제기 → 해결 약속.
- 맛보기: 실제 본문 한 쪽을 그대로 보여줘요. 챕터 번호 + 주장형 제목("200콜 상담사는 일단 돌리고, 50콜 상담사는 먼저 분류한다"), 본문은 장면으로 시작.

**가져올 것**
- 소개문 공식(장면 → 원인 → 주는 것)
- 공감 체크리스트로 "내 얘기"라고 느끼게 하기
- 맛보기는 요약이 아니라 실제 본문 그대로
- 주장형 챕터 제목
- 카드의 "누구에게 맞는지" 표시

**가져오지 않을 것**
- "필독서 1위", "상위 1%"처럼 근거를 댈 수 없는 배지와 표현
- 정가를 높게 적고 큰 할인율을 보여주는 방식
- 소개 전체를 긴 이미지 한 장으로 만드는 방식(느리고, 검색과 화면 읽기 도구에 안 잡혀요)

## 2. 마공사 (클래스유 강의)
**구성**
- 제목: "사수 없는 주니어 마케터를 위한 <검색광고 실무 패키지>". 독자의 상황 + 받는 것.
- 커리큘럼: 번호 체계(0-1, 1-1, 1-2)와 강의별 시간, 첫 강 무료.
- 강사 소개: 경력과 운영 브랜드 나열.
- 구매 압박: 카운트다운, "남은 자리 18", 단계별 가격 인상 예고.

**가져올 것**
- 독자 상황으로 시작하는 제목
- 목차에 번호와 분량(장 수, 걸리는 시간)을 같이 보여주기
- 첫 부분 무료 공개

**가져오지 않을 것**
- 카운트다운, 남은 수량 같은 긴급성 장치(전자책은 수량이 없어서 거짓이 돼요)
- 경력 나열로 신뢰를 만드는 방식(99BOOKS는 경력을 지어낼 수 없어요. 신뢰는 작성 시점·도구·버전 표기와 맛보기로 만들어요)

## 3. 게으른빌더 (무료 가이드)
**구성**
- 가이드 카드 설명 2문장: "~하고 싶은데 막막합니다. ~하면 ~할 수 있습니다."
- 가이드 맨 위: "읽는 데 7분, 섹션 2개, 2026-11-08 공개" + "이 자료에 담긴 것" 목차.
- 준비물을 번호로(준비물 1, 2, 3).
- 번호 붙은 단계마다: 할 일 2~3줄 → 복사 박스(라벨: PROMPT, CONNECTOR URL) → 확인 방법("남은 크레딧과 플랜이 나오면 성공이에요") → 주의할 점.
- 고를 것이 있으면 표로(방법 / 무엇을 / 팁).

**가져올 것**
- 맨 위 메타 줄(분량, 공개일)
- 단계마다 "이렇게 나오면 성공"이라는 확인 방법
- 복사 박스에 종류 라벨 붙이기
- 카드 설명 2문장 공식(문제 + 해결)
- 선택지는 표로

**가져오지 않을 것**
- 이메일을 내야 볼 수 있는 방식
- 조회수·팔로워 수 자랑
- "인생을 바꾸는" 같은 큰 약속, "여러분" 호칭

## 4. 스레드의 무료 전자책
**패턴**
- 무료 전자책을 연락처 수집용으로 써요. "댓글 달면 보내드려요", "프로필 링크에서 받으세요".
- "99,000원 상당 무료", "3일 뒤 글 삭제", 수익·조회수 인증으로 후킹해요.
- 같은 스레드 안에서 이런 방식을 "무조건 거르라"는 반응도 보여요. 피로감이 쌓인 방식이에요.

**가져올 것**
- 첫 줄에 받는 결과를 한 문장으로 말하기
- 무료로 볼 수 있는 곳을 한 군데로 모으기(99BOOKS는 오늘의 칼럼과 앞 3장 무료)

**가져오지 않을 것**
- 정가 부풀리기, 삭제 예고, 수익 인증, 댓글 요구

## 5. 스킬에 반영한 결론
| 결론 | 반영한 곳 |
|---|---|
| 맛보기는 실제 본문 그대로, 요약으로 대신하지 않는다 | 상세페이지 스킬의 `preview` 블록 |
| 소개문은 장면 → 원인 → 주는 것 | 상세페이지 스킬의 `hero` 문구 규칙 |
| 공감 체크리스트 | 상세페이지 스킬의 `for-whom` 블록 |
| 긴급성 장치·부풀린 정가·근거 없는 배지 금지 | 상세페이지 스킬의 금지 목록, 검수 스킬 |
| 신뢰는 작성 시점·도구·버전으로 | 전자책 제작 스킬의 준비물 장, 상세페이지 `facts` 블록 |
| 단계마다 확인 방법 | 전자책 제작 스킬의 단계 장 규칙 |
| 준비물 번호, 복사 박스 라벨 | 전자책 제작 스킬 |
| 주장형 챕터 제목, 번호와 분량이 보이는 목차 | 전자책 제작 스킬, 상세페이지 `toc` 블록 |
| 카드 설명 2문장 공식 | 전자책 제작 스킬의 한 줄 소개 규칙 |
