# 99BOOKS 문체 적용

99BOOKS에 올라가는 글을 쓰거나 고칠 때는 아래 순서를 그대로 따른다. 규칙의 근거와 예시는 `docs/writing-style.md`에 있다.

## 1. 시작 전에 읽는다
1. `docs/writing-style.md` 전체
2. `CLAUDE.md`의 "내용 규칙" 절
3. 칼럼을 쓸 때는 `docs/samples/column-sample.md` (검사기 합격본)

## 2. 종류를 정한다
| 종류 | 검사기 type | 구조가 적힌 곳 |
|---|---|---|
| 오늘의 칼럼 | `column` | writing-style.md 4장 |
| 전자책 슬라이드형 (미니북, 실전 키트) | `slide` | writing-style.md 5-1 |
| 전자책 긴 글형 (심화 가이드 챕터) | `deep` | writing-style.md 5-2 |
| 표지 문구 | `slide` (표지는 book.json 안에 있다) | writing-style.md 5-3, 7장 |
| 상세페이지 문구 | 문체 검사기 대신 `node scripts/detail-check.mjs <slug>` | `detail-page` 스킬 |

## 3. 뼈대부터 쓴다
- 제목과 소제목을 먼저 쓴다. 소제목은 주제가 아니라 그 구역의 결론을 말하는 문장이다.
- 칼럼의 첫 문단은 숫자, 장면, 질문 중 하나로 시작한다. 인사와 예고로 시작하지 않는다.
- 긴 글형 챕터는 "이 장을 마치면 → 먼저 알아둘 것 → 따라 하기 → 자주 막히는 곳 → 나쁜 예와 좋은 예 → 점검표" 순서를 지킨다. 이 여섯은 `##`로, 따라 하기 안의 단계는 `### 1. 동작`으로 쓴다.

## 4. 본문을 쓴다
- 해요체. "~습니다"는 사실을 못 박는 문장에만, 평서문의 20% 이하. 한 문장 평균 25~42자, 60자를 넘으면 나눈다. 한 문단 1~3문장.
- 숫자에는 기준 시점과 출처를 붙인다. 확인하지 못한 사실은 쓰지 않는다.
- 기준 시점은 출처를 실제로 연 날짜만 쓴다. 다른 문서에서 옮겨 온 수치에 오늘 날짜나 그 문서의 날짜를 "확인한 날"로 붙이지 않는다. 그럴 때는 "○○ 문서 기준"이라고 쓴다.
- 분량을 채우려고 근거 없는 문장을 넣지 않는다. 모자라면 예시나 예외를 더하고, 그래도 모자라면 짧은 채로 둔다.
- 전문가다운 말투는 단정 + 근거 + 조건으로 만든다. 경력을 내세우거나 "직접 해 봤어요"라고 쓰지 않는다.
- 독자는 상황으로 부른다. "여러분"은 쓰지 않는다.

## 5. 검사기를 돌린다
```bash
node scripts/style-check.mjs <파일> --type column
node scripts/style-check.mjs <챕터 파일> --type deep
node scripts/style-check.mjs src/books/<slug>/book.json --type slide
```
- 불합격(✗)이 0개가 될 때까지 고친다. 기준을 낮추거나 검사기를 고쳐서 통과시키지 않는다.
- 주의(△)는 `docs/writing-style.md` 6장의 예시처럼 고칠 수 있으면 고친다. 인용문이라서 남기는 경우에만 둔다.

## 6. 검사기가 못 보는 것을 직접 확인한다
- [ ] 첫 문장이 숫자·장면·질문 중 하나인가
- [ ] 소제목만 이어 읽어도 글의 흐름이 보이는가
- [ ] 모든 수치와 고유명사에 출처가 있고, 조사 시트에 기록했는가
- [ ] 한 주제를 출처 3곳 이상에서 확인했는가. 특정 글의 구성이나 문장을 따라 쓰지 않았는가
- [ ] 한계와 예외를 본문에 밝혔는가
- [ ] 수익·성공 보장, 투자 종목·시점, 의학적 효과 주장이 없는가
- [ ] 전자책이면 작성 시점, 도구 이름, 버전이 준비물 장에 있는가
- [ ] 칼럼이면 "그래서 무엇을 하면 되는지"를 말하는 우리 관점 한 단락이 있는가
- [ ] 칼럼 끝의 책 연결은 내용이 실제로 이어지는 책이 있을 때만 넣었는가 (없으면 넣지 않는다)
- [ ] "확인 필요" 같은 채우지 않은 자리가 남아 있지 않은가

## 7. 보고한다
검사기 출력(합격 여부, 주의 개수)과 6번 점검 결과를 그대로 알린다. 확인하지 못한 항목은 확인하지 못했다고 쓴다.
