# 권한 창을 읽고 허락하거나 거절해요

## 이 장을 마치면

클로드 코드가 허락을 묻는 창을 한 번 허락하고, 한 번 거절해 봐요. 폴더마다 어떤 권한 모드로 시작할지 정한 표도 하나 남아요.

## 먼저 알아둘 것

권한 모드는 클로드 코드가 나에게 묻지 않고 해도 되는 일의 범위예요. 입력 상자 아래 줄 오른쪽 끝 칸에서 고르고, 세션 중에도 언제든 바꿀 수 있어요.

채팅창의 클로드는 답을 글로만 보여줘요. 클로드 코드는 내 컴퓨터의 파일을 실제로 만들고, 고치고, 옮겨요.

그래서 일을 하기 전에 나에게 물을지 말지를 미리 정해 두는 장치가 필요하고, 그것이 권한 모드예요. 묻는 순간이 곧 내가 확인할 기회예요.

목록에는 다섯 가지가 있어요. 앱 화면의 이름과 설명, 공식 안내의 동작을 함께 정리하면 아래와 같아요.

| 모드 | 화면의 설명 | 묻지 않고 하는 일 |
|---|---|---|
| 자동 | Claude가 권한 결정을 처리합니다 | 작업 폴더 안의 파일 작업 대부분. 위험해 보이는 작업은 따로 걸러서 막아요 |
| 수동 | 변경하기 전에 항상 확인 | 파일 읽기와 읽기만 하는 명령. 파일을 바꾸거나 명령을 실행하기 전에는 물어요 |
| 편집 자동 수락 | 모든 파일 편집을 자동으로 수락 | 파일 만들기와 고치기, 옮기기, 복사, **지우기**까지. 그 밖의 명령은 물어요 |
| 계획 | 변경하기 전에 계획 세우기 | 파일을 읽고 살펴보기만 해요. 파일은 고치지 않고 계획을 내놓아요 |
| 권한 무시 | Claude Code 설정에서 활성화 | 거의 묻지 않아요. 설정에서 켜야 보이고, 이 책은 쓰지 않아요 |

표에서 가장 중요한 줄은 편집 자동 수락이에요. 2장에서 연습 폴더에 쓴 이 모드는 파일 지우기도 묻지 않고 해요. 연습 폴더에서는 편하지만, 진짜 폴더에서는 위험할 수 있어요.

자동 모드도 작업 폴더 안의 파일 작업은 대부분 묻지 않고 해요. 위험한 일을 걸러 주기는 하지만, 내 파일의 이름이 바뀌는 일은 일상적인 작업으로 보고 그대로 진행할 수 있어요. 앱을 처음 켰을 때 이 칸이 "자동"으로 되어 있을 수 있으니, 진짜 폴더를 열 때는 꼭 확인해요.

수동 모드에서는 허락 창이 떠요. 공식 안내에 따르면 이 창은 클로드 코드가 하려는 일을 먼저 보여주고, 그 아래에 고를 수 있는 답을 보여줘요. 답은 크게 세 가지예요. 이번 한 번만 허락하기, 허락하고 다음부터 묻지 않기, 거절하기예요. 화면의 글자는 앱 버전에 따라 조금 다를 수 있어요.

새 파일을 만들 때는 들어갈 내용 전체가 창에 보여요. 이미 있는 파일을 고칠 때는 바뀌기 전과 바뀐 뒤가 함께 보여요.

공식 안내는 이것을 "정확히 무엇이 변경될지 보여주는 화면"이라고 설명해요. 창에 보이는 대로만 일이 일어나니, 창을 읽는 것이 곧 결과를 미리 보는 일이에요.

## 따라 하기

### 1. 연습 폴더에서 수동 모드로 바꿔요

사이드바의 **새로 만들기**로 새 세션을 열고, 폴더 칸의 "최근"에서 `클로드연습`을 골라요. 권한 모드 칸을 눌러 **수동**을 골라요.

![권한 모드 목록의 수동과 계획](/books/claude-code-start/ch3-modes.svg)

모드 칸에 "수동"이 보이면 준비가 끝났어요. 2장에서 이 폴더에 편집 자동 수락을 골랐다면, 여기서 수동으로 바꾼 모드가 이 폴더에 새로 기억돼요. 이제부터는 파일을 바꾸기 전에 클로드 코드가 먼저 물어요.

### 2. 메모 하나를 만들게 하고 허락해요

입력 상자에 아래 입력값을 보내요.

```입력값 3
"오늘 할 일.txt"라는 메모를 하나 새로 만들어줘.
내용은 "1. 연습 폴더 정리하기" 한 줄이면 돼.
```

잠시 뒤 허락 창이 떠요. 바로 누르지 말고 두 가지를 읽어요. 첫째, 만들거나 바꾸려는 파일 이름이 `오늘 할 일.txt`인지 봐요. 둘째, 들어갈 내용이 내가 요청한 한 줄과 같은지 봐요.

둘 다 맞으면 이번 한 번만 허락하는 답을 골라요. 파일 탐색기에서 `클로드연습` 폴더를 열어 새 메모가 생겼는지 확인해요.

### 3. 파일을 지우게 하고 거절해요

같은 대화에 아래 입력값을 보내요.

```입력값 4
방금 만든 "오늘 할 일.txt"를 지워줘.
```

이번에도 허락 창이 떠요. 지우기는 명령을 실행하는 일이라 수동 모드에서는 반드시 물어요. 창에서 지우려는 파일 이름을 확인한 뒤, 이번에는 거절하는 답을 골라요.

파일 탐색기에서 메모가 그대로 있는지 확인해요. 거절하면 그 일은 일어나지 않아요. 공식 안내에 따르면 아무 말 없이 거절하면 클로드 코드는 거기서 멈추고 다음 요청을 기다려요.

거절할 때 이유를 함께 적을 수 있는 경우도 있어요. 이유를 적으면 클로드 코드가 그 이유를 읽고 다른 방법으로 계속 일해요. 예를 들어 "지우지 말고 이름 앞에 '보관_'을 붙여줘"라고 적으면 지우는 대신 이름을 바꾸려고 해요.

허락 창을 기다리지 않고 일을 멈추고 싶을 때도 있어요. 그럴 때는 클로드 코드가 일하는 동안 보이는 중지 버튼을 누르면 돼요. 클로드 코드가 하던 일을 그 자리에서 멈춰요.

이미 끝난 일은 되돌려지지 않으니, 멈춘 뒤에는 파일 탐색기에서 어디까지 바뀌었는지 확인해요.

### 4. "다시 묻지 않기"는 아직 고르지 않아요

허락 창에는 허락하면서 다음부터 묻지 않게 하는 답도 있어요. 공식 안내에 따르면 파일 수정은 그 세션이 끝날 때까지, 명령은 그 폴더에서 앞으로도 계속 묻지 않게 돼요.

손에 익기 전까지는 이 답을 고르지 않아요. 매번 묻는 것이 번거롭다면 연습 폴더에서는 편집 자동 수락을 쓰고, 진짜 폴더에서는 한 번씩 확인하는 편이 안전해요.

### 5. 폴더별 시작 모드를 정해요

이 책에서 쓰는 기준은 아래 표예요. 이 표를 메모장에 옮겨 두고, 새 세션을 열 때마다 모드 칸과 대어 봐요.

| 폴더 | 시작 모드 | 이유 |
|---|---|---|
| 연습 폴더 | 편집 자동 수락 | 가짜 파일뿐이라 잃을 것이 없어요 |
| 진짜 폴더, 처음 하는 일 | 계획 | 아무것도 바꾸지 않고 계획부터 받아요 |
| 진짜 폴더, 계획을 확인한 뒤 | 수동 | 바뀌는 파일을 하나씩 보고 허락해요 |

권한 모드는 폴더마다 기억돼요. 공식 안내에는 새 세션이 설정에 저장된 기본 모드로 시작할 수도 있다고 적혀 있어요. 그래서 첫 메시지를 보내기 전에 모드 칸을 한 번 보는 습관이 가장 확실해요.

표의 둘째 줄과 셋째 줄은 4장과 5장에서 그대로 따라 해요. 4장에서는 계획 모드로 정리 계획표를 받고, 5장에서는 그 계획을 확인한 뒤에 실행해요.

연습 폴더에서 이 순서를 한 번 몸에 익혀 두면, 7장에서 진짜 폴더로 옮길 때도 같은 순서로 하면 돼요.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 허락 창이 뜨지 않고 바로 파일이 생겨요 | 모드가 자동이나 편집 자동 수락이에요 | 모드 칸을 눌러 **수동**으로 바꾼 뒤 다시 요청해요 |
| "권한 무시"가 흐리게 보이고 눌리지 않아요 | 설정에서 켜야 쓸 수 있는 모드예요 | 정상이에요. 이 책은 이 모드를 쓰지 않아요 |
| 실수로 지우기를 허락했어요 | 창을 읽지 않고 눌렀어요 | 연습 폴더라면 입력값 1로 파일을 다시 만들어요. 명령으로 지운 파일은 휴지통을 거치지 않을 수 있어요 |
| 허락 창이 계속 떠서 일이 진행되지 않아요 | 바꿀 파일이 많은 요청을 수동 모드에서 보냈어요 | 연습 폴더라면 편집 자동 수락으로 바꿔요. 진짜 폴더라면 4장처럼 계획부터 받아요 |

허락 창이 뜨면 습관처럼 파일 이름부터 읽어요. 내가 고른 폴더 안의 파일인지, 내가 요청한 파일인지만 봐도 실수 대부분을 막을 수 있어요.

파일 이름 다음에는 바뀌는 양을 봐요. 한 줄을 고쳐 달라고 했는데 창에 수십 줄이 바뀐다고 나오면, 요청을 다르게 이해한 거예요. 그럴 때는 거절하고 요청을 더 좁혀서 다시 보내요.

## 나쁜 예와 좋은 예

| 구분 | 하는 일 | 결과 |
|---|---|---|
| 나쁜 예 | 허락 창이 뜰 때마다 읽지 않고 허락해요 | 요청과 다른 파일이 바뀌어도 알아채지 못해요 |
| 좋은 예 | 파일 이름과 바뀔 내용을 확인한 뒤 허락해요 | 요청과 다르면 그 자리에서 거절할 수 있어요 |
| 나쁜 예 | 진짜 업무 폴더를 편집 자동 수락으로 열고 "정리해줘"라고 보내요 | 이름 바꾸기와 지우기가 묻지 않고 진행될 수 있어요 |
| 좋은 예 | 진짜 폴더는 계획 모드로 열고 계획부터 받아요 | 무엇이 바뀔지 먼저 보고, 확인한 뒤에 수동 모드로 실행해요 |

첫 번째 쌍의 차이는 읽는 습관이에요. 허락 창은 내가 무엇을 허락하는지 보여주려고 뜨는 창이에요.

두 번째 쌍의 차이는 시작 모드예요. 같은 요청이라도 어떤 모드로 보내느냐에 따라 내가 확인할 기회가 생기기도 하고 사라지기도 해요.

## 점검표

- [ ] 연습 폴더에서 권한 모드를 "수동"으로 바꿨어요
- [ ] 메모 만들기를 파일 이름과 내용을 확인한 뒤 허락했어요
- [ ] 메모 지우기를 거절하고, 파일이 남아 있는 것을 확인했어요
- [ ] "다시 묻지 않기"는 고르지 않았어요
- [ ] 폴더별 시작 모드 표를 메모장에 옮겨 뒀어요
