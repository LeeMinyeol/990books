# 뼈대: ai-work-insight (첫 인사이트 책)

2026-11-16: 사용자가 이 주제를 첫 인사이트 책으로 정하고 2장부터 이어 쓰기로 함.
2026-11-15. 사용자 요청: 따라 하기 책은 990원, 9,900원은 분양의신 아카데미처럼 인사이트를 담은 전자책. 내용이 적으면 가격을 조정한다. 처음에는 형식을 보기 위한 샘플(1장만)이었다. 2026-11-16에 6장까지 씀.

## 따라 하기 책과 다른 점
| | 따라 하기(claude-code-start) | 인사이트(이 책) |
|---|---|---|
| 독자가 얻는 것 | 결과물 하나 | 판단 기준과 관점 |
| 다시 볼 이유 | 거의 없음 | 일할 때 기준표로 다시 꺼냄 |
| 장 구조 | 고정 6구역(이 장을 마치면 … 점검표) | 장면 → 근거 → 해석 → 한계 → 내 일에 대입 → 한 줄 |
| 장 제목 | 할 일("계획표를 먼저 받아요") | 주장("경계는 울퉁불퉁해요") |
| 근거 | 공식 문서 | 연구 논문, 공식 보고서, 1차 데이터 |
| 지어내지 않기 | 경력·후기 금지 | 같음. 경험담 대신 연구 속 실제 장면을 쓴다 |

## 장 구조(인사이트형)
- 첫 절: 연구 속 실제 장면으로 시작한다. 가상의 인물·사례를 만들지 않는다.
- 근거 절: 숫자마다 누가 낸 숫자인지 문장 안에 밝힌다("논문 요약에 따르면", "BCG는").
- 한계 절: 참가자, 시기, 환경의 한계를 적는다. 숫자보다 방향을 보게 한다.
- "내 일에 대입해 보기": 독자가 자기 일로 채우는 표 하나.
- "이 장의 한 줄": 장의 주장을 한 문장으로.

## 분량 메모(2026-11-16)
6장까지 합계 15,001자(공백 제외, book-check 기준). 기준(15,000자)을 겨우 넘었다. 검수에서 문장을 줄이면 기준 아래로 내려갈 수 있으니, 줄일 때는 같은 장에 근거를 보태서 맞춘다. 가격 조정 여부는 사용자가 정한다.
