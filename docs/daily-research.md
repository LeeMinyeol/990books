# 매일 조사 절차

매일 아침 예약 작업이 이 문서를 그대로 따른다. 사람이 손으로 돌릴 때도 같다.
조사 시트의 구조와 적는 규칙은 [research-sheet.md](research-sheet.md)에 있다. 먼저 읽는다.

- 시트 ID: `1pPTKPZn3MoQ3JwpCyFGdthwEQHzSRVM3Lmdy84XqBfA`
- 검색어 목록: `scripts/research-queries.json`
- 수집 스크립트: `scripts/youtube-research.mjs`
- 임시 파일 위치: `.research/daily/` (git에 올라가지 않는다)

## 1. 시트에 이미 있는 것을 읽는다
1. `콘텐츠!A2:A`와 `콘텐츠!J2:J`를 읽는다. A열에서 앞글자별(C, N, D, Y) 가장 큰 번호를, J열에서 영상 주소를 얻는다.
2. J열 주소를 줄마다 하나씩 `.research/daily/known.txt`에 쓴다.
3. `책 기획!A2:D`와 `책 기획!O2:O`를 읽는다. 기존 후보의 ID, 분야, 제목, 상태를 알고 있어야 새 줄을 연결하고 겹치는 후보를 만들지 않는다.

## 2. 수집한다
```bash
node scripts/youtube-research.mjs --period week --limit 6 --known .research/daily/known.txt > .research/daily/today.json
```
- 결과는 `items`(새 영상)와 `errors`(실패한 검색어)다. 최소 조회수는 분야마다 `research-queries.json`의 `min`을 쓴다. 실패한 검색어는 스크립트가 두 번 다시 시도한 뒤에 남은 것이다.
- 명령이 실패하거나 `items`가 비고 `errors`만 있으면 4단계를 건너뛰고 5단계 메일에 실패 내용을 적는다. 스크립트를 고치려고 하지 않는다.

## 3. 고른다
`items`에서 아래를 뺀다. 뺀 개수는 메일에 적는다.
- 수익·부업 금액을 내세우는 영상("월 1,000만 원", "수익 공개", "떡상"으로 돈을 약속하는 것)
- 투자 종목·매매 시점, 건강·의학 효과 주장
- 뉴스, 정치, 예능, 브이로그처럼 주제와 상관없는 것
- 외국 채널 영상(제목이 자동 번역된 것. 채널 이름에 한글이 없고 제목이 어색한 번역투이면 외국 채널로 본다)

남은 것에서 **최대 15개**를 고른다. 분야마다 조회수 단위가 달라서(AI는 수만~수십만, 노션·데이터 분석은 수천) 전체를 한 줄로 세우지 않는다.
1. AI가 아닌 분야(노션, 데이터 분석, 유튜브 운영)에서 분야마다 조회수가 높은 순으로 최대 3개씩 먼저 고른다.
2. 남은 자리를 AI에서 조회수가 높은 순으로 채운다.
3. 남은 자리가 있으면 아직 안 고른 것에서 조회수 순으로 채운다.

## 4. 시트에 적는다
### 콘텐츠 탭
`콘텐츠!A:L`에 줄을 덧붙인다(append). 열 순서와 값:

| 열 | 값 |
|---|---|
| 번호 | 앞글자 + 이어지는 두 자리 번호 (예: C33) |
| 수집일 | 스크립트의 `collectedAt` |
| 분야 | `category` |
| 검색어 | `query` |
| 제목 | `title` 그대로 |
| 채널 | `channel` |
| 조회수 | `views` (숫자) |
| 올라온 때 | `published` 그대로 (수집일 기준) |
| 길이 | `length` 앞에 작은따옴표를 붙인다 (예: `'26:06`). 붙이지 않으면 시트가 시각으로 바꿔 버린다 |
| 주소 | `url` |
| 읽은 신호 | 제목에서 읽은 수요 한 줄. 지어내지 않는다. 영상 내용은 보지 않았으므로 내용을 단정하지 않는다 |
| 연결된 책 ID | 기존 후보와 이어지면 ID, 없으면 빈칸 |

### 책 기획 탭 (새 후보가 있을 때만)
- 오늘 고른 콘텐츠가 기존 후보 어디에도 이어지지 않고, 같은 신호가 2개 이상 보일 때만 새 후보를 만든다. **하루 최대 2개**. 없으면 만들지 않는다. 만들지 않는 날이 대부분이어도 괜찮다.
- 16칸을 모두 채운다. 형식과 말투는 기존 줄을 따른다. 상태는 `후보`.
- `CLAUDE.md`의 상품 구성, 돈 낼 이유(넷 중 셋 이상), 내용 규칙을 지킨다. 수익·조회수 약속, 투자·건강 주장은 넣지 않는다.
- 도구·요금제를 확인하지 않았으면 "제작 때 확인"이라고 적는다. 분야가 헷갈리면 마지막 칸에 적는다.
- 미니북과 심화 가이드를 새로 만들 때는 기존 후보와 범위가 겹치지 않는지 본다.

## 5. 요약 메일을 보낸다
- 받는 사람: 예약 작업 지시문에 적힌 주소 하나. 다른 곳으로 보내지 않는다.
- 제목: `[99BOOKS] 오늘의 조사 YYYY-MM-DD`
- 본문(일반 텍스트, 해요체, 마크다운 기호 없이):
  1. 한 줄 요약: 새 콘텐츠 N개, 새 책 후보 N개
  2. 오늘 눈에 띈 콘텐츠 최대 5개: 분야, 제목, 채널, 조회수, 주소
  3. 새 책 후보: ID, 종류, 제목, 근거 한 줄 (없으면 "오늘은 없어요")
  4. 뺀 것: 이유별 개수
  5. 실패: 실패한 검색어와 이유 (없으면 생략)
  6. 시트 주소: https://docs.google.com/spreadsheets/d/1pPTKPZn3MoQ3JwpCyFGdthwEQHzSRVM3Lmdy84XqBfA/edit
- 수집이 실패한 날도 메일은 보낸다.
